> 💬 引用: The interesting thing about AI agents is that as a theoretical matter, their inference can kind of run anywhere. AI is one of the few areas of technology that isn’t *as* sensitive to latency back to the user. 
> 
> Long running agents are now going to be the norm, which means it’s ok to send off work to an AI factory somewhere and that work can essentially be largely done within that remote data center and a final result spit back to the user. The data can pass into these systems in an encrypted manner, be combed through by agents, and then disregarded right after. 
> 
> And because the economic value of the task is so high relative to the latency sensitivity (eg getting back $500 in value from an automated task, but it takes an extra second to return), you don’t have to have the inference to be particularly close to the user. 
> 
> Also, because inference is a temporary process with no sensitive data needing to be stored long term where the inference is happening, you can effectively treat AI factories as ephemeral systems, changing some of the data residency dynamics slightly.
> 
> Combined, this means you have more flexibility in where you can begin to deploy AI data centers. This is both a huge economic opportunity for the states or countries (or space) that want to take advantage of this fact. And it’s a loss to the states or countries that decide to forgo the opportunity.
> 🇨🇳 AI agent的有趣之处在于，从理论上讲，它们的推理可以运行在任何地方。AI是少数对用户端延迟不那么敏感的技术领域之一。

长时间运行的agent如今将成为常态，这意味着把工作发送到某处的AI工厂是可以的，这些工作基本上可以在那个远程数据中心内完成，然后将最终结果返回给用户。数据可以以加密的方式传入这些系统……
