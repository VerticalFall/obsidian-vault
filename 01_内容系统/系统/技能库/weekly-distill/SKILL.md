# weekly_distill · 周度蒸馏

> 脚本：`01_内容系统/知识库/每日日报/.github/scripts/run_weekly_distill.py`
> 模型：DeepSeek（环境变量 `ROUTER_MODEL`，默认 `deepseek-v4-pro`）

## 这是什么 / 何时用

- **自动**：GitHub Action 每周一自动跑，产出草稿 `_蒸馏/W{ISO周}-draft.md`。
- **手动**：本技能用于——本地重跑生成草稿，以及更重要的 **人工审核定稿**。
- 定稿路径：`01_内容系统/系统/蒸馏/W{周}.md`（草稿头部会标注最终路径）。

## 脚本做什么（DeepSeek 三件事）

1. **信号群合并**：跨天聚类，标注成熟度 🌳可写级 / 🌿发酵中 / 🌱早期 / 🍂消退中
2. **冷却判断**：选题池瘦身——哪些降温、哪些归档（**单日波动不降级，多日无信号才降级**）
3. **沉淀可复用框架 + 观点回顾**：对照 `_观点.md` 判断是否有需修正的信号（AI 只提议，用户确认才写入）

## 执行步骤

1. **生成 / 确认草稿**：
   ```powershell
   cd "C:\Users\user\Documents\Obsidian Vault\01_内容系统\知识库\每日日报"
   python .github/scripts/run_weekly_distill.py
   # 预览（只写草稿，不修改选题池）：
   $env:DRY_RUN = "1"; python .github/scripts/run_weekly_distill.py
   ```
2. **读草稿** `_蒸馏/W*-draft.md`。
3. **人工审核定稿**：
   - 成熟度分级是否合理；
   - 冷却判断是否克制（单日波动不降级）；
   - 可复用框架是否有沉淀价值；
   - `_观点.md` 修正：AI 提议 → 用户确认 → 写入并追加变更记录。
4. **定稿**：把草稿复制到 `01_内容系统/系统/蒸馏/W{周}.md`，标注来源与日期。

## 选题池维护（随蒸馏必做，P-20260808-04）

1. **🔥 区冷却**：超过 7 天的选题逐条判断——仍有信号 → 移入 🌿；信号消退 → 移入 💤 或归档；执行后更新节头条数。
2. **表格卫生**：删除模板残留行（含 `<` 占位符的行）；核对同一选题是否重复出现，去重。
3. **空节清理**：把条目已归档的**空节**（表头下无数据行）整节删除，防止历史空壳积累。

## 输出校验（交付前自查）

- [ ] 定稿已落在 `01_内容系统/系统/蒸馏/`，命名 `W{周}.md`（或可识别标签）
- [ ] 冷却 / 归档动作与草稿一致，选题池未被误清空
- [ ] `_观点.md` 有改动时，变更记录同步追加

## 红线

- **观点修正必须用户确认**后才写入 `_观点.md`；AI 只给信号，不给结论。
- 冷却判断要克制：单日波动不降级，多日无信号才降级。
- **定稿是人工动作**：脚本草稿不等于定稿，草稿未审核不得进入 `系统/蒸馏/`。
