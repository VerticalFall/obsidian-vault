### P-20260808-01 · 微信 AI 机器人（CowAgent + GitHub MCP，读取全部 / 写入收件箱）

**功能升级 · P1 · ⏳ 待验收**（交付物完成 2026-08-08；部署到朋友服务器为用户侧操作）

#### 要解决什么

知识库只在 PC 本地可读写，人不在电脑前无法查询/记录；远程备份单向 push，无远程入口（观测）。

#### 方案

1. 部署 CowAgent（chatgpt-on-wechat v2 继任）到朋友内网服务器，接个人微信——手机/PC 无需访问该服务器，同步走 GitHub 中转
2. GitHub 集成 = 官方 MCP server（零代码，配置 `~/cow/mcp.json`）
3. 凭证 = 细粒度 PAT，仅授权 `obsidian-vault` 单仓库（Contents 读+写，其余一律 No access）
4. 写入沙箱 = 技能层约束：路径必须以 `01_内容系统/系统/inbox/` 开头、命名 `微信-YYYYMMDD-HHmm.md`、inbox 外一律拒绝
5. 模型 = DeepSeek V4 Flash（Web 控制台直配）

#### 验收标准

- [ ] 微信查《漫步华尔街》核心观点 → 返回内容（读取）
- [ ] "记下某想法" → 远程 inbox 新文件 → 同步回本地可见（写入+同步）
- [ ] 负测试：让机器人修改 inbox 外文件 → 被拒绝（沙箱）
- [ ] PAT 审计为仅 obsidian-vault 单仓库

#### 验证记录（2026-08-08）

交付物完成：`01_内容系统/系统/机器人/README.md`（架构/能力边界/三层安全/风险清单）+ `部署指南.md`（阶段 0-5 + 验收测试表 1-5）+ mcp.json 配置 + 收件箱技能提示词；待用户按指南部署后回填。

3. **朋友服务器可信环境**：CowAgent 提示"仅在可信环境部署"——凭证最小化 + 收件箱沙箱缓解；部署前确认服务器出站可达 github.com
4. **未核实项**：个人微信登录方式细节（扫码/hook 协议版本）需部署时按其文档核实

### P-20260808-02 · 知识库每日双向同步（本地 ↔ vault-backup）

**链路 · P1 · ⏳ 待验收**（已实施并验证 2026-08-08；验收 1/2/4 通过，验收 3 观察中）

#### 要解决什么

vault-backup 仅每周一由 weekly-backup 单向 push；远程产生的改动（机器人收件箱、手机端）无机制回到本地；冲突策略无约定（观测）。

#### 方案

1. 新增 `01_内容系统/系统/scripts/sync-vault.ps1`：`pull --ff-only` → 有新内容则 `add -A && commit && push` → 全程日志
2. Windows 计划任务：每日 13:00 + 登录时（与 pull-reports 同机制：user / Interactive / Limited / StartWhenAvailable）
3. 冲突策略：本地为权威——`--ff-only` 失败则 stash → pull → pop；仍冲突则中止并告警，绝不自动覆盖任一方
4. weekly-backup 技能降级为手动快照兜底（每日自动同步接管）
5. 每日日报子仓库不受影响（根仓库 .gitignore 已排除）

#### 验收标准

- [x] 本地改文件 → 计划任务 push → 远程 vault-backup 可见（本地→远程）
- [x] 远程手工提交 `inbox/` 文件（模拟机器人写入）→ 计划任务 pull → 本地可见（远程→本地）
- [ ] 连续 3 天无人干预自动跑通、日志无异常（⏳ 观察中，PM 下次巡检复核）
- [x] 人为制造冲突 → 任务中止并告警、零数据覆盖（冲突保护）

#### 验证记录（2026-08-08）

- sync-vault.ps1 已建（UTF-8 BOM，避免 PS 5.1 中文解析问题）；逻辑：`pull --ff-only` → 失败则 stash -u 重试 → 仍失败 FATAL 中止 → `add -A`（无改动跳过）→ commit → push → 全程日志
- 计划任务已注册：`ObsidianVault-SyncVault-13h`（每日 13:00）+ `ObsidianVault-SyncVault-Logon`（登录时）
- 收件箱目录 `01_内容系统/系统/inbox/` 已建（含 README 约定，机器人写入唯一允许位置）；`sync-vault.log` 已加入 .gitignore
- weekly-backup 技能已降级（技能库 README 同步更新）
- 实测：本地→远程 `fdc7b0b..30a1ad0`；远程→本地拉回成功；冲突测试 FATAL exit=2、stash 保留本地版本、零数据丢失，清理后远程无残留
