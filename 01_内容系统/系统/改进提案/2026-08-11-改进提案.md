## P-20260811-01 · 信息源扩增（分层落地）

- 类型：功能升级
- 现状与问题：（观测）四源均为 AI/科技方向，跨领域输入为零；（需求）用户明确要求扩增投资/政治/体育/GitHub 周榜/影响力内容，可接受周更频率
- 影响面：选题池输入广度、每日报告覆盖面、router 漏斗输入
- 改进方向与方案：

  **架构**：新增两个渲染器，边际成本极低——
  - `render_rss.py`：配置驱动（`_sources/feeds.json` 维护 RSS 列表），一个脚本覆盖所有 RSS 类源，输出 `RSS-Feeds/YYYY-MM-DD.md`（后续加源=改一行 JSON）
  - `render_github_trending.py`：周更，官方 GitHub Search API（`created:>DATE&sort=stars`，免 token），输出 `GitHub-Weekly/YYYY-W##.md`

  **Phase 1（稳定源，零 key、官方/RSS）**：
  | 源 | 方向 | 频率 | 依据 |
  |----|------|------|------|
  | GitHub Search API 周榜 | 开源项目 | 周 | 官方 API，模拟 trending 周榜（无官方 trending API 的通行方案） |
  | Hacker News（Firebase API） | 技术社区热点 | 日 | 官方公开 API，免费无限，极稳 |
  | BBC Sport / BBC News RSS | 体育/时政 | 日 | 免费 RSS，覆盖足球/网球/F1/板球/高尔夫 |
  | Al Jazeera / DW / France24 / CGTN RSS | 国际时政（多视角） | 日 | 免费 RSS，跨意识形态视角 |
  | arXiv API | 学术前沿 | 日 | 官方 API，免费 |
  | Yahoo Finance RSS | 财经速览 | 日 | 免费 RSS |

  **Phase 2（中文源，逆向接口，标注风险）**：
  | 源 | 方向 | 风险 |
  |----|------|------|
  | 财联社电报（`cls.cn/api/cache`） | A 股/宏观快讯 | 🟡 逆向接口，改版即失效（社区当前主流方案，akshare 旧接口已下线） |
  | 知乎热榜 | 中文舆论场 | 🟡 逆向接口 |
  | 微博热搜 | 中文舆论场 | 🔴 封禁风险高，默认不做（备选） |

  失败策略：所有新源 `continue-on-error`（与现有四源一致），中断仅告警不影响主链路；`check_health.py` 增加新源覆盖检查。

- 优先级：P1
- 状态：待执行
- 验收标准：
  1. Phase 1 全部源上线后，连续 7 天（周更源 2 周）产出正常，无中断
  2. `check_health` 新增新源检查项，任一源中断触发 🔴/🟡 告警
  3. 新增源不改变现有四源链路与 router 行为（回归验证：router 输入自动含新源后选题池正常）
  4. 上线成本为零（无新增付费服务）；Phase 2 逆向源每接入一个需单独评估稳定性并回填验收

## P-20260811-02 · 每日专属新闻报告（统合所有源）

- 类型：功能升级
- 现状与问题：（观测/需求）现有报告按源分文件（AI-HOT/X-Tweets/TrendRadar/FollowBuilders/新源），读者每日需打开 4+ 个文件拼全貌；用户要求"统合成一份每日专属新闻报告"
- 影响面：直接消费端（用户每日阅读入口），与 router（写作选题漏斗）功能不重叠
- 改进方向与方案：
  - 新产物 `_每日精选/YYYY-MM-DD.md`：每日 12:20 Action 在四源渲染 + 路由之后追加一步 `render_daily_digest.py`：
    - 读当日全部源报告 → DeepSeek 单次调用汇总（复用现成 DEEPSEEK_API_KEY）
    - 结构：**跨领域要闻 Top 5-8**（AI/科技/财经/政治/体育/国际各领域混合排序）→ 每领域速览 3 条 → 每条带一句点评（复用 [[_观点]] V1-V7/A1-A6 锚点，注明）→ 来源链接
    - 成本估算：~$0.02-0.05/天（DeepSeek，按 router 单价推算）
  - 可选（同提案内 Phase 2）：周一随蒸馏生成《周度综述》（周更源 + 蒸馏信号群整合，替代 W33-draft 的人工开头）
  - 命名与链路：与 `_路由/` 并列，随每日报告同步到本地与远程
- 优先级：P1
- 状态：待执行
- 验收标准：
  1. 上线后连续 7 天产出 `_每日精选/YYYY-MM-DD.md`，无中断
  2. 内容字段完整：≥3 个领域、≥8 条要闻、每条含来源链接；点评标注观点锚点（无锚点的标"独立观察"）
  3. 每日成本可观测且 < $0.1（在每日健康报告中记录新增检查项"精选成本"或由 DevOps 抽样观测）
  4. 不影响 router/选题池链路（回归验证）
