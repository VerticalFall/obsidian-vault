## 一、stock-monitor Agent 化升级解剖 🔬
以自己亲手写的仓库做"大模型 Agent 怎么设计"的最佳一手案例——把 stock-monitor 从「定时批跑→推报表」重构成：

**六大 Agent/AI 工程亮点**
- a) **自研轻量 ReAct 引擎（弃用 LangGraph）**：<65KB `agent_engine.py` 手写；明记 ADR「降依赖、先交付」；7 工具注册表
- b) **"技能即配置"场景层**：纯规则/关键词零 LLM 成本分类，rubric 外置 `prompts/scenarios/*.txt`
- c) **长期记忆→打分检索→回灌 system prompt**：stdlib SQLite(WAL) 三表；纯 SQL 打分；ADR 记「不上 FTS」（CJK 2 字名 trigram 失效）
- d) **克制型反思/self-critique**：草稿≤500token 自检，命中问题才警示，否则回 OK 不重写——阈值化降本
- e) **SSE 真流式 + 断连 GET-poll 双通道兜底**：拆 reasoning_content、tool_calls 跨 delta 重组、Last-Event-ID 续传
- f) **后台任务化 + 并发闸 + 架构克制**：后台 job（1 running+1 queued，双满 409）；pipeline_state 全局单闸「被占用则不接管」；MCP 仅记 ADR
