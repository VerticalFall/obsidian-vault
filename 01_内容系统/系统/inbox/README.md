## 约定

- **机器人写入**：仅允许写本目录，文件名 `微信-YYYYMMDD-HHmm.md`；其他路径一律拒绝（沙箱）。
- **本地处理**：本地确认内容后移出本目录（归入 `01_内容系统/` 对应位置），或直接删除；本目录不留积压。
- **冲突策略**：远程写入面限制在本目录（同文件双写概率≈0）；若仍冲突，同步任务中止并告警，不覆盖任何数据（见 `01_内容系统/系统/scripts/sync-vault.ps1`）。
- **自动化**：本目录随 vault-backup 分支每日 13:00 + 登录时双向同步（计划任务 `ObsidianVault-SyncVault-13h` / `-Logon`）。
