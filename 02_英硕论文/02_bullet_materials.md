## §2 Background 可用素材

- PhraseBank 四个一致度子集（嵌套）：AllAgree 2,264 条 / >75% 3,453 / >66% 4,217 / >50%（全集）4,846
- 一致性阈值含义：100% = 全部标注者一致；75/66/50 = 严格大于该阈值
- Ng–Jordan 核心主张（转述）：判别式渐近误差 ≤ 生成式（数据无穷时）；但生成式估计误差可能 O(log n) 收敛，判别式 O(n) → 存在交叉点，小样本生成式占优

## §3 Methodology 可用素材

- 特征：TF-IDF，1–2gram，min_df=2，English stopwords，sublinear_tf，两模型共用同一向量器
- NB：MultinomialNB，α=1（Laplace）；SVM：LinearSVC，C=1
- RQ1：80/20 分层切分固定 held-out test；规模 [32,64,128,256,512,1024,2048,3877]；5 seeds；per-subset 为主 + fixed-pool 稳健性
- RQ2：(a) 子集内 10 折 CV；(b) 固定干净测试集=AllAgree 留出 20%；(c) 固定 n=600 非重叠区间（all 2264 / 75–100 1190 / 66–75 765 / 50–66 627）
- RQ3：四配置（NB 经验先验 / NB 均匀先验 / SVM 无权重 / SVM balanced）；指标 neg-F1+recall / macro-F1 / accuracy
- 评估：分层 10 折 CV、5 seeds、mean±std

## §4 Results 可用素材（核心数据碎片）

### 4.1 Baseline（全量 50Agree，10 折 CV）
- NB：acc 0.698，macro-F1 0.516
- SVM：acc 0.757，macro-F1 0.691
- 差距：acc +0.059，macro-F1 +0.175

### 4.2 RQ1 学习曲线（per-subset，accuracy）
- n=32：NB acc 0.600±.012 > SVM 0.576±.010（差 0.024）
- n=64：NB 0.616 > SVM 0.570（差 0.046，全程最大）
- n=128：NB 0.620 > SVM 0.598
- n=256：NB 0.641 > SVM 0.636（NB 仍微领先）
- n=512：SVM 0.659 > NB 0.657（SVM 首次反超）
- → 交叉点位于 n≈256–512 之间；5/5 seeds 均出现 SVM 反超
- macro-F1：SVM 全规模占优（n=32 时 0.389 vs 0.317；满量 0.681 vs 0.501）
- fixed-pool 模式：SVM 连 accuracy 也全规模占优（n=32 0.596 vs 0.594）→ 词表随样本学习是 NB 小样本优势来源之一

### 4.3 RQ2 噪声劣化
- (a) 子集内部 CV macro-F1：NB 0.623(100%) → 0.515(50%)；SVM 0.802 → 0.691
- (a) 数据量反增（2264→4846）而性能反降 → 标签不确定性效应 > 数据量效应
- (b) 固定干净测试集：SVM 0.766(100%训练) → 0.777(50%训练)，基本持平；NB 0.607 → 0.626
- (b) 含义：低一致度标签大体正确，不伤干净泛化；说明 (a) 下降部分来自测试集更难
- (c) 固定 n=600：NB macro-F1 0.548(all) → 0.357(75–100) → 0.306(66–75) → 0.312(50–66)
- (c) SVM：0.707 → 0.575 → 0.390 → 0.438
- (c) NB 负类 F1：0.169 → 0.073 → **0.000**（66–75 区间，recall 为 0）→ 0.108
- (c) SVM 负类 F1：0.561 → 0.384 → 0.209 → 0.332

### 4.4 RQ3 类别不平衡
- NB 经验先验：neg-F1 0.256，neg-recall **0.151**（仅抓 15%），neg-precision 0.891（高精度低召回），macro-F1 0.515，acc 0.698
- NB 均匀先验：neg-F1 **0.513**（+0.257），neg-recall 0.456（×3），macro-F1 **0.632**（+0.117），acc 0.714（+0.016，同时上涨）
- SVM 无权重：neg-F1 0.598，neg-recall 0.516，macro-F1 0.691，acc 0.757
- SVM balanced：neg-F1 **0.612**（+0.014），neg-recall 0.582（+0.066），macro-F1 0.695（+0.004），acc 0.752（−0.005）
- 最优恢复后：SVM balanced neg-F1 0.612 仍 > NB 均匀先验 0.513

## §5 Discussion 可用素材（只列现象，不下结论）

- 现象 A：accuracy 上存在 Ng–Jordan 交叉；macro-F1 上不存在
- 现象 B：NB 的负类在默认/小样本/低一致三种情形下都最脆弱（recall 0.151 / macro-F1 全规模落后 / neg-F1→0）
- 现象 C：NB 均匀先验同时提升 accuracy 与 macro-F1（罕见，经验先验下 NB 过度偏向 neutral）
- 现象 D：样本量恒定下，标签一致性是决定性因素（n=600 时 100%→50–66% 区间 SVM macro-F1 0.707→0.438）
