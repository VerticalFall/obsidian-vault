# 段落结构模板（Paragraph Templates）

> **用法**：每段按"结构提示"组织你的论点。`[洛哥填：...]` 处是你的论证内容——**我绝不预填措辞**。
> 结构是通用的"主张句 → 证据 → 对比/解释 → 小结"骨架，填入的内容和深度完全由你决定。

## 通用建议（写作节奏）

1. 一段一个主张；主张句放段首。
2. 数据点只报事实，解释放 Discussion。
3. 数字引用图表："As shown in Fig. X / Table Y, ..."
4. 每段写完，回看简报（`01_section_briefs.md`）确认核心命题没跑偏。
