# drafts/ 工作流说明

## 两个目录的职责（证据链分离，§4.4）

- **`scaffolds/`** — Claude Code 产出的**骨架辅助**（写作简报、要点清单、题注、模板、文献）。
  - 这些是**素材**，不是论文内容。正文里的任何句子必须由洛哥写出。
- **`prose/`** — **洛哥撰写的正文**（论文实际内容）。
  - 建议：每节一个文件，如 `prose/section4_results.md`，写完由洛哥自己归档版本。

## 使用流程（初稿 8/18–21）

1. 动笔前：读对应节的 **01_section_briefs.md**（论证骨架 + 必引数据/图/表）
2. 取数据碎片：**02_bullet_materials.md**（短语级，自行组句）
3. 组织段落：**04_paragraph_templates.md**（结构提示 + `[洛哥填：]`）
4. 配图配表：**03_figure_captions.md**（题注可直接用，但"说明了什么"的解读自己写）
5. 引文献：**05_references.md**（✅ 已核实 / ⚠️ 待核实）
6. 骨架总览：**00_thesis_skeleton.md**

## 合规边界提醒（§1.1 口诀）

> 如果 Claude 产出的东西你可以**不加实质性思考直接复制粘贴**进论文——那就是越界了。
> 骨架辅助允许做重、做细，但**正文措辞永远出自你手**。
