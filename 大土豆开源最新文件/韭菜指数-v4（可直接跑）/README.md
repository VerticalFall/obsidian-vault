# 韭菜指数 v4.0 —— 新生产体系

> 建立于 2026-10-17。本文件夹是韭菜指数的**生产工具包**；每日产出仍归档到 `Desktop\韭菜指数\`。
> 旧体系（SKILL v1.3 + 109 个历史文件夹）保留原地未动，迁移等用户确认。

## 文件结构

```
韭菜指数-v4\
├── SKILL.md                      ← 唯一权威规范（三产品线/字数预算/三层信息法/验证闭环/数据规范）
├── README.md                     ← 本文件
├── references\
│   ├── scoring-v4.md             ← 五温度计锚定公式（可复算/可回测）
│   ├── template-上午.html        ← 上午版模板（≤1500字）
│   ├── template-全天.html        ← 全天版模板（≤3000字）
│   └── template-周报.html        ← 周报模板（≤3500字，含验证命中率统计）
└── demo\
    └── 10月16号-全天-韭菜指数-v4demo.html   ← 实测样本：原版格式精简版 6017→4806字（-20%），1160px宽版、全结构保留
```

## 使用方法（每期）

1. 读 `SKILL.md` → 复制对应模板 → 采集当日数据 → 替换 `{{占位符}}` → 自检字数。
2. **禁止从上一期报告复制**——上一期是最大路径依赖源。

| 维度 | v3.4 | v4.0 |
