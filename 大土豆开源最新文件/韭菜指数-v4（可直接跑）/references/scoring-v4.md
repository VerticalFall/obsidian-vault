# scoring-v4.md —— 五支温度计锚定公式（v4.0 当前生效）

> 目标：每个分数**可复算、可回测、可对答案**。打分前先查数，查完按表对号入座，禁止凭语感。

---

## 〇、通用色阶（五档，全报告统一）

| 分数段 | 色阶 | 标签 | 主色 |
|:---:|:---:|:---:|---|
| 85-100 | 🔴 红 | 过热 | `#c0392b` |
| 70-84 | 🟠 橙 | 温暖 | `#ff7a00` |
| 45-69 | 🟡 黄 | 中性 | `#c8a415` |
| 30-44 | 🟢 青绿 | 偏冷 | `#2e9c82` |
| 0-29 | 🟢 绿 | 冰冷 | `#0a8f5b` |

数据源：通达信（tdx-connector）实时/收盘快照，财联社盘中预估。所有输入**必须记录采集时间和具体数值**，写进数据 MD。

---

## 一、市场热度 = 市场整体活不活跃

**输入 A**：今日成交额（上午版用预计全天）÷ 近 20 日日均成交额
**输入 B**：上涨家数占比（涨/(涨+跌)）

| A（量比） | 基础分 |
|:---:|:---:|
| ≥ 150% | 90 |
| 120%-150% | 78 |
| 100%-120% | 65 |
| 80%-100% | 50 |
| < 80% | 32 |

**B 修正**：上涨占比每偏离 50% ±10 个百分点 → ±4 分（上限 ±8）。

> 语义：与「讨论热度」严格区分——市场热度看**绝对量级**（vs 20日均值），讨论热度看**环比变化**。

---

## 二、赚钱效应 = 今天持仓的人赚不赚

**输入 A**：上涨家数占比；**输入 B**：涨停家数 ÷ 近 20 日日均涨停家数；**输入 C**：最高连板高度

| A | 基础分 |
|:---:|:---:|
| > 70% | 70 |
| 50%-70% | 55 |
| 30%-50% | 40 |
| < 30% | 25 |

| B（涨停倍数） | 修正 |
|:---:|:---:|
| ≥ 2.0× | +15 |
| 1.0-2.0× | +8 |
| 0.5-1.0× | 0 |
| < 0.5× | −10 |

| C（连板高度） | 修正 |
|:---:|:---:|
| ≥ 7 板 | +10 |
| 4-6 板 | +5 |
| 2-3 板 | 0 |
| 全断板 / 高度 1 | −5 |

总分 clamp 到 [0, 100]。

---

## 三、讨论热度 = 人声鼎沸还是冷清（成交额环比口径）

**唯一输入**：今日成交额环比昨日全天（%）

| 环比 | 分数段 | 语义 |
|:---:|:---:|---|
| > +30% | 85-100 | 巨量过热，人人都在聊 |
| +10% ~ +30% | 70-84 | 放量升温 |
| ±10% | 45-69 | 平量，正常节奏 |
| −10% ~ −30% | 30-44 | 缩量降温 |
| < −30% | 15-29 | 冰点，没人说话 |

段内取值按环比线性插值。**本维度禁止使用封板率/涨停家数**——那是恐贪情绪的输入，不得重复表达同一件事。

---

## 四、恐贪情绪 = 散户追高意愿

**输入 A**：封板率 = 收盘仍涨停数 ÷ 盘中曾触涨停数（炸板含分母）
**输入 B**：连板高度修正

| 封板率 | 分数段 | 语义 |
|:---:|:---:|---|
| ≥ 80% | 80-100 | 资金封板坚决，散户敢追高 |
| 60%-80% | 65-79 | 偏贪婪 |
| 40%-60% | 45-64 | 观望拉扯 |
| < 40% | 25-44 | 炸板潮，恐慌占上风 |

**B 修正**：连板高度 ≥ 5 板 → +8；炸板率 > 50% → −8。clamp [0,100]。

> 恐贪高 ≠ 会涨。它只描述「散户此刻敢不敢追」，往往反向提示情绪过热。

---

## 五、风险偏好 = 资金防御还是进攻

**唯一输入**：进攻组当日均涨幅 − 防御组当日均涨幅

- 进攻组：券商、半导体/科技、军工、资源（有色煤炭）
- 防御组：银行、白酒、电力、公用事业

| 差值 | 分数段 | 语义 |
|:---:|:---:|---|
| ≥ +1.5% | 85-100 | 全面进攻 |
| +0.5% ~ +1.5% | 65-84 | 偏进攻 |
| ±0.5% | 45-64 | 平衡 |
| −0.5% ~ −1.5% | 25-44 | 偏防御 |
| < −1.5% | 10-24 | 全面避险 |

组内板块可按当期主线替换（如军工低空成主线时入进攻组），但**每期必须在数据说明里写明本期的进攻组/防御组构成**。

---

## 六、输入缺失处理

| 缺失项 | 处理 |
|---|---|
| 近 20 日均值（涨停/成交额） | 用近 10 日代替，数据说明标注 |
| 封板率（曾触涨停数查不到） | 恐贪情绪改用「涨停家数 + 连板高度」二输入版，标注降级 |
| 板块组涨幅（个股级数据缺失） | 用通达信行业指数代替 |

**任何降级处理必须在报告「数据说明」区注明**——读者有权知道哪个分数是缩水版。

---

## 七、回测指引（验证锚定公式本身）

- 每周六周报顺手做：抽查本周 5 个交易日的「恐贪情绪 ≥ 80」样本，统计次日大盘涨跌——若恐贪高分次日上涨概率 > 60%，说明锚定公式有反向价值；若完全无规律，考虑调锚点。
- 更严格回测（月度一次）：调 `_archive` 历史 HTML 抽 20 期，人工复算温度计 vs 当日实际打分，偏差 > 15 分的维度优先修公式。
