# 巴菲特公司研究助手 · 水友分享版 v2.1

**中文名称：巴菲特公司研究助手。启动口令：巴菲特研究＋公司名称或代码。**

第一次使用，先上传本包的 `巴菲特公司研究助手-通用精简版.md`，或安装本技能；之后在能读取本指引的会话中，输入一句话即可：

```text
巴菲特研究 贵州茅台（600519），生成Excel和图表。
```

把公司换成你要研究的公司即可。仅输入 `巴菲特研究 贵州茅台` 时，助手会先问需要文字、Excel还是Excel＋图表，并可同时开始收集资料。

其他用法：

```text
巴菲特研究 宁德时代（300750），只要文字报告。
巴菲特研究 招商银行（600036），生成Excel，不需要图表。
巴菲特研究 福耀玻璃（600660），重点检查分红是否可持续，生成Excel和图表。
```

换到新会话时，需重新上传指引，或确认该产品已安装并能发现本技能。文件和图表制作仍取决于当前产品的工具能力。

从生意、管理层、财务、现金流、分红、估值和风险研究公司，按需制作Excel与图表。保留原八份理念参考，新增数据溯源、分行业估值与Excel交付规范。

这是一套研究指引，不包含实时数据库或文件生成服务。不同模型可以读同一套指引；联网、计算、xlsx和图表制作取决于产品提供的工具。不宣称已在所有模型上测试。

## 水友怎么用

### 普通聊天模型：不用安装skill

解压分享包，优先上传 `巴菲特公司研究助手-通用精简版.md`，输入上面的中文口令即可。需要指定更多要求时，也可使用下面的长指令：

```text
请使用我上传的巴菲特研究指引，研究【公司名称＋代码＋上市市场】。
核实截至今天已公开的最新财报，区分经营数据日期与股价日期。
交付：完整研究＋Excel＋可编辑图表。
解释公司怎么赚钱、护城河、管理层、财务现金流、分红可持续性，
用适合行业的方法做三情景估值、安全边际与风险跟踪。
事实、假设、判断分开，关键数据给来源。
无法联网或生成xlsx时，请明确说明并交付可用替代材料。
```

只要文字：交付改成“文字报告，不要Excel和图表”。只要表格：改成“Excel，不需要图表”。不确定就写“先问我是否需要Excel及图表”。已明确要图表时不会重复确认。

精简版包含完整执行流程。想深入阅读原理念参考，可补上传指定参考文件或 `巴菲特公司研究助手-通用完整版.md`。完整版较长，先确认模型能完整读取，超出上下文则分文件提供，不能让模型假装已读完。

### 支持原生Skills的智能体

将整个 `skills/buffett/` 文件夹（含入口与全部参考）导入产品指定的技能目录或技能导入功能。不同产品安装路径不同，按该产品说明操作。安装并可被发现后，同样输入 `巴菲特研究＋公司名称或代码`。内部标识 `buffett` 保留以兼容原有技能；对外名称与启动口令均为中文。本包不会自动安装或改设置。

## Excel与图表

完整研究建议包含“一图流、生意与护城河、财务与现金流、分红与股东回报、估值与假设、风险与跟踪、数据与来源”，小任务可合并。参数可编辑、衍生值用公式、来源日期留在文件内。

图表按用户选择与数据条件制作：业绩、现金转化、分红、三情景价值与现价、敏感性等；银行换成净息差、不良、信用成本、资本。优先原生可编辑图表。

仅能聊天的产品可交付分表数据、公式、图表说明和必要脚本，不能保证直接下载Excel。没做重算或视觉检查必须说明。
