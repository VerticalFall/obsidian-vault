## 完整研究流程

1. **证据底稿**：必读[09 数据与来源](references/09-data-and-sources.md)。分别列研究日、财报日、公告日、价格日，查证最新报告是否发布。通常覆盖五个完整年度及最新可比中期，历史不足按实际说明，不凭记忆填数。
2. **生意与治理**：读[03 护城河](references/03-business-moat.md)、[04 治理](references/04-management-governance.md)，按行业读[08](references/08-industry-playbooks.md)。拆收入、利润、客户、地区、竞争与资本需求。每项护城河有证据、反证、趋势和可证伪指标；区分技术壁垒、制造规模、组装能力和订单景气。核对增持/回购承诺与完成、注销与激励、分红与融资、收购效果；管理层买入价不是估值底线。
3. **财务与分红**：读[05](references/05-financial-metrics.md)，并执行09、10的口径修正。分析收入利润、利润率、ROE/ROIC、现金、应收存货、资本开支、债务和稀释。区分归母、扣非、合并及普通股口径。红利公司区分年度/LTM/预测股息率、普通/特别分红、已实施/公告/假设，检验现金与资本是否支持分红。
4. **分行业估值**：必读[10](references/10-valuation-and-industry.md)，按需读[06 资本配置背景](references/06-valuation-capital.md)。至少两种适用且尽量独立的方法；缺数据可只用一种并降低可信度。完整研究给悲观/基准/乐观驱动、过程、区间、安全边际和敏感性；不可靠时只给条件估值，不强算目标价。不为凑数量机械平均。
5. **反证与监控**：读[07](references/07-risk-behavior.md)，找出最可能造成永久损失的三条路径。持有/卖出问题逐条检验价格过高、生意恶化、诚信受损、更优机会；最后一项需要明确可比对象。监控写成“指标—当前值/未知—触发条件—后续核查”。不给无依据个人仓位、杠杆或收益保证。
6. **交付与检查**：要Excel/图表时读[11](references/11-excel-and-charts.md)，核对来源、单位、公式、情景、图表及可读性；没有重算或渲染就如实说明，不能凭保存成功声称验证通过。

## 完整报告内容

用用户语言和大白话，区分事实、计算、假设、判断。结构可调整，完整公司研究包含：一句话结论及可信度；数据边界与能力圈；生意/护城河；治理资本配置；财务现金债务和分红；三至五项假设；行业适配估值、三情景、安全边际、敏感性；三项关键风险及监控；决定性来源。持有/卖出场景补四项检验。有文件附真实链接及验证状态。

结论可为“值得深研／价格有吸引力但需条件验证／观察／回避”，给原因，不把评分与目标价包装成确定买卖指令。数据不足可交付局部研究，显式保留未知，不为填模板捏造。

# 数据、来源与可比期间

## 证据账本

决定性输入追溯到：资料名、发布方、直接链接/附件名、发布日期、报告期间、页码/表名、原始值与单位、标准化值、数据状态。无法取得页码或日期则说明，不能猜。网页摘录作线索，关键值回原表；上传文件用文件名与页码定位。

标记**披露事实、计算结果、分析假设、研究判断、缺失/待核实**。第三方数据列提供方，与官方冲突时说明差异和处理理由。来源只证明相应事实，不能把自设增长率说成年报披露。

分别显示财报日、股价日、研究截止日和检索日期。历史时点研究不得使用截止日后发布资料；可单列“期后信息”。离线材料注明版本。

## 单位与口径

- 金额可用亿元或百万元，每表固定标注；每股用元/股，市场、币种明确。跨币种记录汇率、日期、来源。
- 百分比存小数，如0.15显示15%；百分点与基点分开，1个百分点=100bp。
- 收入/CFO通常合并口径，归母利润和净资产是归母口径，ROIC是经营口径；差异须解释。
- 股价采用指定日收盘价或注明盘中时间；休市日用前一交易日并标注。原始价用于市值估值，复权/含息序列用于相应历史回报，不混用。
- 核对多类股份、ADS、送转拆股、增发、回购、转债。每股价值用估值时点适用普通股数，重要稀释单列；EPS加权平均股本不无说明替代期末股本。普通股权益扣除适用优先股/永续工具权益。

## 期间

- 同比用相同长度和可比并表/会计口径；半年对去年半年，前三季度对去年前三季度。
- 流量TTM=上一完整年度＋本年累计同期−上年累计同期，三个原始期间必须齐全。资产负债表是时点数，不能TTM相加。
- 单季流量=本年累计−本年上一季度累计；ROE等平均余额指标不能直接相减。
- 不机械半年乘二；实际、年化、预测分别标记。年化ROE说明方法，季节性、补助、减值和周期要单独考虑。
- 重述、准则变化、并表或资产出售须注明，不能拼接成虚假增长。历史不足五/十年按实际列示，缺失不记零，不造十年ROIC。

## 分红与回购

每笔分红记录所属财年、普通/特别、税前DPS、币种、实施状态及取得的公告/除息/支付日期。年度、LTM、预测分别计算，防止重复；送转后追溯可比每股值。

股息率=对应税前DPS/同币种现价。税前与个人到手金额不混。普通股派息率=普通股现金股利/对应普通股利润，亏损年不显示正常正派息率。FCF覆盖率明确分子分母，负FCF不说成可持续分红。

回购区分计划、实际支付、注销、库存股用途；增持区分自有资金、员工计划、承诺和完成，同时核对减持/稀释。

## 核对

资产≈负债＋权益；现价、股数和市值一致（多类股分别处理）；现金流期初＋变动＋汇兑等调节≈期末；收入利润EPS/DPS对应正确期间和股数；图表、摘要、估值引用同一底稿。

冲突先查原表、单位币种、合并/归母、累计/单季。无法解决隔离相关结果，交付核实部分和缺口，不造数。

# 估值、情景与行业适配

本文件优先于旧参考中的经验倍数、固定折价和通用ROIC/现金转化门槛。这些门槛不是通用定价标准，也不是已核验的巴菲特原话。

## 通用约束

先解释利润是否正常、现金能否分配、周期位置。每种方法列适用条件、期间、公式、参数理由和局限。至少两种适用方法，缺数据宁可减少；两种相近利润倍数不算独立验证。历史分位、同行定价和内在价值是不同证据，低分位不自动便宜。

三情景用经营驱动推出：销量/收入、利润率、资本需求、现金转化、增长衰退、折现/估值参数，不只在目标价上下加减20%。悲观不等于最坏损失，乐观不是承诺。

有依据且口径可比才综合估值，列权重、贡献且总和100%；共享同一假设的方法不能重复计权。也可保留分歧不综合。

## 股权价值与企业价值

- FCFF按WACC折现得到企业价值。股权价值=企业价值＋未计入经营现金流的非经营资产−有息债务−适用少数股东及其他优先索取权。租赁、受限现金、投资、养老金按对应口径处理，不能重复加减。
- FCFE/归属普通股的所有者收益按股权成本Ke折现，结果已是股权价值，不再无理由扣净债务。
- 归母利润与合并折旧/营运资金不能直接拼接。无法桥接少数股东等差异时，改用合并FCFF再扣相应索取权，或降低所有者收益法权重。
- 每股价值=普通股股权价值/估值时点适用股数；重要稀释另列。

## 非金融公司

FCF代理=经营现金流−全部现金资本开支，核对无形资产、租赁等遗漏。它不自动等于所有者收益或FCFE。

所有者收益估计=合适利润口径＋对应非现金费用−维持性资本开支−必要营运资金增加，另处理其他非现金项目/债务资金流。CFO通常已扣营运资金变动，不能重复扣。未披露维持开支时给有依据区间、敏感性及扣全部资本开支的保守检查，不能把未证实的开支全说成增长投入。

FCFF=EBIT×(1−适用税率)＋D&A−全部资本开支−Δ经营营运资金。营运资金排除融资债务和非经营现金。

ROIC=可比NOPAT/平均经营投入资本，说明现金、商誉、租赁处理；投入资本异常或为负不能硬算优秀回报。

DCF终值=第N+1年现金流/(折现率−永续增长率)，再折回估值日，折现率必须>g。FCFF用WACC，FCFE用Ke；增长、再投资和回报率自洽。展示终值占比及折现率×g敏感性，不能永续的业务不强用永续。

PE交叉检查=正常化普通股EPS×有依据PE。倍数联系增长、周期、回报、风险，不搬用“好公司20倍”。

## 分行业选择

| 类型 | 关键分析 | 估值交叉检查 | 避免 |
|---|---|---|---|
| 成熟消费/服务 | 复购、渠道、定价、单店经济、现金 | 所有者收益/DCF＋历史/可比PE | 名气等于护城河，只选繁荣期 |
| 制造/组装/出海 | 产品结构、良率产能、客户集中、应收存货、汇率 | 正常化PE＋FCFF/所有者收益；差异大用SOTP | 按科技标签给软件倍数，订单当收入现金 |
| 软件/成长 | 留存付费、竞争、研发经济性、股权激励、单位经济 | 多阶段DCF＋适用可比，盈利不稳做条件情景 | 研发全加回却不计未来投入 |
| 煤油/资源 | 价格位置、成本曲线、销量储量、税费复垦、维持投入 | 中周期现金/利润＋资源NAV或分红 | 高点利润×低PE；资源无限永续 |
| 电力/公用事业 | 电价、利用小时、燃料水情、长协、回款、杠杆开支 | 分类型FCFF/DDM＋可比，适用时PB–ROE | 火水核风光混套；政策机制未经当期核实 |
| 银行 | NIM、拨备前利润、信用成本、不良迁徙、资本派息 | 剩余收益＋DDM，PB–ROE/历史同行校验 | 套CFO−Capex、工业ROIC、净债务/EBITDA |
| 保险 | 财险承保/浮存金成本；寿险NBV/CSM、资产负债、偿付能力 | 适用P/EV、调整PB、DDM、分业务 | 寿财险同一利润倍数，忽略准则差异 |
| 控股/多元 | 分部、母公司债务、交叉持股、少数股东 | SOTP/NAV＋适用分部方法 | 重复计子公司现金债务或投资价值 |

银行稳定期PB=(可持续普通股ROE−g)/(Ke−g)，Ke>g且资本留存与g自洽。剩余收益=(ROE−Ke)×期初普通股权益；价值=初始权益＋未来剩余收益现值（含适用终值）。DDM对可分配普通股股利折现，派息满足资本要求。三者共享假设，不是三份完全独立证据。

保险EV/NBV等未披露或口径不一致时不可伪造，该方法标不可用。

## 分红与安全边际

区分可重复盈利、一次性收益、积累现金、举债派息。非金融看多年FCF、维护投入、债务；银行保险看可分配利润、资本与监管约束。特别股息不能当永续。

股息率估值=可持续普通DPS/要求税前股息率，只是收益要求的价格锚，不等于完整价值，仍有增长下降和本金风险。

- 相对价值V的安全边际=1−现价/V；要求V>0、现价有效，负数代表溢价，不截零。
- 上涨空间=V/现价−1，两者不能混称。
- 条件观察价=V×(1−所需安全边际)，折价参数须解释，不强制所有公司同一比例。
- 分别展示相对基准和悲观价值的安全边际、币种、价格日期。无法可靠估值就写未知，不给假精确目标价。
- 便宜不能补救无法评估的生意或不可接受的永久损失风险。

# Excel与图表交付规范

仅用户要文件/图表时使用。尊重给定模板；完整研究可用下表，小任务按需合并，不硬建空表。

| 表 | 内容 |
|---|---|
| 一图流 | 怎么赚钱、研究结论、价格/财报日期、关键指标、价值区间、三项风险；需要图表时集中展示关键图 |
| 生意与护城河 | 分部/地区/客户、竞争优势及反证、管理层资本配置 |
| 财务与现金流 | 五年＋最新可比期、利润质量、应收存货、开支、债务和可比指标 |
| 分红与股东回报 | 年度/LTM/预测DPS、普通/特别、覆盖、回购注销、增减持稀释；不适用可合并 |
| 估值与假设 | 唯一输入区、依据、三情景过程、安全边际和敏感性 |
| 风险与跟踪 | 风险路径、指标触发、后续核查；持有问题四项检验 |
| 数据与来源 | 原始值、期间/单位/口径、定位、调整、缺失；多时另分原始数据和来源 |

一图流不只放目标价，要看见生意、盈利现金、股东回报和风险；无图表时保留一页摘要。

## 数据与公式

原始数据和假设分开，输入→计算→估值→摘要/图表，不多处手填同一数。输入浅蓝/蓝字、公式深色、来源引用绿色、假设浅黄、风险浅红，并附图例；颜色辅助文字。

衍生值尽量用Excel公式，关键参数可编辑并说明更新位置；跨表引用加引号。使用环境支持的常用公式，不伪造计算缓存。缺失、不适用与0分开，不能用 `IFERROR(...,0)` 掩盖错误。历史实际、TTM和预测清晰标记。

文件本身有研究日、财报截止日、价格日、市场、币种、单位及来源，离开聊天仍可理解。

## 图表（用户需要时）

选能回答问题且数据齐备的3—5张，不凑数，缺数据就减少并说明。

| 问题 | 推荐 | 核对 |
|---|---|---|
| 业绩变好了没？ | 年度趋势＋最新同比；量级不同分图或标明双轴 | 不把全年、半年、TTM连成假趋势 |
| 利润变现金了吗？ | 非金融利润/CFO/FCF并列，附口径差异 | CFO合并、利润归母的差异须说明 |
| 分红稳吗？ | 普通/特别DPS柱图＋派息率或覆盖图 | 实施、公告、预测分开 |
| 价格贵吗？ | 情景价值柱图＋现价参考线；方法对比 | 同币种同每股单位，情景非收益承诺 |
| 最大变量？ | 敏感性热力表/驱动对比 | 每格真计算，不仅改色 |
| 银行好转没？ | NIM、信用成本、不良、资本分图 | %/bp分清，不套工业CFO |

分部结构优先横向条形/堆积图，不用3D装饰。不编造历史股价；价格/含息曲线须有真实数据及调整说明。

优先原生可编辑图表，引用真实底表范围并随重算更新；注明标题、单位、期间、图例，缺失不画零，预测用不同颜色/虚线。柱图通常从零起，截断轴显著说明；不能遮挡表格。新增期间要扩展图表范围并核对。图片只作补充并标“静态”、日期及更新办法。

## 可读性

中文易读字体，标题约16—20pt、正文10—12pt，冻结表头，长文换行，列宽/行高足够，金额百分比格式统一。展示单元格默认水平垂直居中，长说明可左对齐。不堆小字、大空白和碎片合并。网址独立列或超链接，别挤压摘要。

## 验证

1. 核对来源、单位、期间、股权/企业价值桥接和估值勾稽。
2. 用实际可用计算引擎重算，检查 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?`、`#NUM!` 等。预期缺失单独标记。
3. 改一个重要参数重算，核对估值、摘要、图表联动，再恢复。设置“打开时重算”不算已验证。
4. 有预览/渲染能力时逐表检查裁切、图表、缩放；无能力注明未做，不能凭文件存在声称通过。
5. 保存重新打开，核对表名、公式、图表及来源链接。

无重算能力可交付含公式文件，但文件与回复显著标“尚未重算，请在表格软件打开后重算”，关键结论用独立算术复核。图表依赖未计算缓存时说明预览可能无数据，需打开重算后检查。无文件能力交付分表数据、公式、图表说明及必要脚本，不能声称已交付xlsx。
