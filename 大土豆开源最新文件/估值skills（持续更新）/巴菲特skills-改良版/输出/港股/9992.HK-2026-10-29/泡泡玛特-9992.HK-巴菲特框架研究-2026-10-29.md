### 0.1 为什么是这个结论

2026H1 营收 171.7 亿元、+23.8%，经调整净利 51.6 亿元、+9.5%，归母净利 50.4 亿元、+10.1%，低于市场预期的 199.8 亿/59.8 亿；增速从 2025H1 的 +204% 断崖式放缓。

Labubu 所属 THE MONSTERS 收入 44.54 亿元、-7.5%，占比从 34.7% 降至 26.0%；海外收入 49.72 亿元、-11.6%，占比从 43.8% 降至 29%；库存周转天数从 123 天升至 201 天。

现价 128.70 港元（¥110.17）对应 11.1 倍 TTM 市盈率、5.8% FCF 收益率；净现金 105 亿元，回购计划 20–50 亿港元。DCF 基准 119 元（HK$139），现价低 7%。

三情景跨度极大：悲观 53 元（Labubu 继续下滑、新 IP 失败）、乐观 203 元（IP 平台化成功）。这不是“稳健复利”生意，仓位应反映不确定性。

### 0.2 什么会改变这个结论

- 上行：盈利增速连续 4–6 个季度高于基准，且不是一次性价格/周期因素。
- 上行：管理层用自由现金流做出高回报的资本配置（回购、并购、扩产）。
- 下行：护城河出现结构性侵蚀，或监管/技术替代改变商业模式。
- 下行：估值本身成为风险——即使生意不变，折现率上升也会压缩倍数。

- 股权价值 = 企业价值（EV）− 净负债 + 非经营投资/理财；每股价值 = 股权价值 ÷ 总股本。

## 2. 生意：八个问题

### 2.1 一句话生意

泡泡玛特把艺术家 IP 变成可量产的潮玩：盲盒、手办、毛绒、MEGA，通过线下门店、机器人商店、线上和海外渠道卖给年轻消费者。高毛利来自 IP 溢价，快迭代来自设计/供应链，风险来自 IP 生命周期。

### 2.2 巴菲特八问

| 问题 | 回答 |
|---|---|
| 1. 我能看懂吗？ | 零售模型能看懂；IP 热度、下一个爆款看不清，这是生意本身的特征。 |
| 2. 护城河是什么？ | IP 矩阵、艺术家签约、渠道与会员社区；护城河不宽，但比单一 IP 公司强。 |
| 3. 定价权有多强？ | 强，盲盒/隐藏款有溢价；但热度退潮时，二手价格和复购会迅速下降。 |
| 4. 需求来自哪里？ | Z 世代情绪消费、收藏、社交分享、海外新用户；非必需，经济下行时弹性大。 |
| 5. 竞争格局？ | 52TOYS、TOP TOY、名创优品、万代/乐高；IP 争夺激烈，渠道门槛不高。 |
| 6. 客户与渠道？ | 线下门店/机器人商店、线上、海外；2026H1 海外占比 29%，线上大幅下滑。 |
| 7. 供应商议价力？ | 代工厂分散，公司掌握设计与 IP；但优质产能和海外物流是瓶颈。 |
| 8. 十年后还在吗？ | 大概率在，但可能不再是“Labubu 公司”；IP 平台化是唯一出路。 |

### 2.3 商业本质

泡泡玛特的本质是“IP 孵化 + 渠道变现”：用艺术家签约和设计能力制造爆款，用门店/机器人商店/线上快速铺货，用会员和二手市场维持热度。爆款带来超额利润，但生命周期短，必须持续制造下一个爆款。

### 2.4 护城河

- **IP 矩阵**：Molly、Skullpanda、THE MONSTERS、星星人等；单一 IP 依赖在下降，但 Labubu 仍占 26%。
- **艺术家与供应链**：签约艺术家、快速打样、小单快反；这是“爆款响应速度”的来源。
- **渠道与会员**：线下门店/机器人商店、海外扩张、会员体系；触达能力强，但租金/库存风险高。

### 2.5 增长从哪里来

- **新 IP 接棒**：星星人 2026H1 收入 26.5 亿元、+580.6%，成为第二大 IP；能否持续是关键。
- **海外**：欧洲及其他 +5.9%，但亚太/美洲线上大幅下滑；本地化团队、供应链和门店是长期机会。
- **品类扩张**：毛绒、MEGA、珠宝、乐园；提高客单价和复购，但稀释品牌稀缺性。
- **门店/机器人商店**：国内加密、海外开店；单店模型和库存周转是约束。

### 2.6 资本强度

中等：capex 约 3.5% 收入（门店、机器人商店、供应链）；存货占用大，2026H1 库存周转 201 天；FCF/NOPAT 约 65%，现金转化弱于净利。

## 3. 管理层与资本配置

### 3.1 管理层

- **王宁**：创始人/CEO，产品直觉强，2025 年 Labubu 全球爆红证明其选品能力；但 IP 平台化仍需时间。
- **海外团队**：多为新入职，本地化执行是 2026 年主要短板；公司承认海外线上下滑与团队经验有关。
- **回购**：2026 年 8 月宣布未来 6 个月 20–50 亿港元回购，显示管理层认为股价低估。

### 3.2 资本配置

- **分红**：DPS 2.7248 港元，按现价股息率约 2.1%；分红率不高，现金优先用于扩张。
- **回购**：20–50 亿港元，相对市值 1,714 亿港元约 1–3%；信号意义大于实质。
- **扩张**：海外门店、供应链、IP 投资；回报率不确定，但比回购更符合成长阶段。

### 3.3 股东回报

- 2025 年 ROE 约 60%+（2026H1 年化 44.5%），IP 峰值带来极高回报；正常化后可能降至 20–30%。
- 2021–2025 年 EPS 从 0.62 元升至 9.61 元，CAGR 98%；2026E EPS 8.3 元，首次下降。
- 以现价买入的回报取决于新 IP：若净利恢复 10% 增长，股息+增长+回购约 8–10%；若 Labubu 继续下滑，可能负回报。

## 5. 估值：贵不贵

### 5.1 方法

以 DCF 为主锚：起始收入 2026E 390 亿元，10 年明确预测，WACC 11.5%、终值增长 3.0%；净现金 105 亿元加回。交叉检查用 P/E、EV/EBIT 与 FCF 收益率。由于 IP 周期，DCF 只作为区间参考，不作为点估值。

### 5.2 情景假设

|---|---|---|---|---|---|---|
| 悲观 | 13.00% | 2.50% | -0.3% | 27.0% | 3.5% | 36.5% |
| 基准 | 11.50% | 3.00% | 5.1% | 35.0% | 3.5% | 46.9% |
| 乐观 | 10.30% | 3.50% | 8.5% | 38.0% | 3.5% | 56.1% |

### 5.3 估值结果

|---|---|---|---|---|---|

### 5.4 概率加权与安全边际

- 权重：悲观 25% / 基准 50% / 乐观 25%。
- 概率加权 = 0.25 × ¥53.4 / HK$62.4 + 0.50 × ¥119 / HK$139 + 0.25 × ¥203 / HK$237 = **¥124 / HK$144**。
- 20% 安全边际价 = 基准 ¥119 / HK$139 × 0.8 = **¥95.3 / HK$111.3**。
- 现价 HK$128.70（¥110.17） 相对基准 低 **7.5%**。

### 5.5 三情景叙事

**悲观：** Labubu 继续下滑、新 IP 未能接棒，2027–2028 年收入 -8%/-5%，利润率降至 27%；WACC 13.0%、终值增长 2.5%。价值 53 元（HK$62）。

**基准：** 2027 年增长 10%，之后逐步降至 3%；星星人等新 IP 部分对冲 Labubu 下滑，利润率 35%；WACC 11.5%、终值增长 3.0%。价值 119 元（HK$139）。

**乐观：** IP 平台化成功、海外本地化改善，2027–2029 年增长 18–13%，利润率 38%；WACC 10.3%、终值增长 3.5%。价值 203 元（HK$237）。

### 5.6 反推 DCF

现价 110 元隐含未来 10 年收入 CAGR 约 4.7%，略低于基准 5.1%；市场没有定价“IP 崩溃”，而是定价“低增长 + 高波动”。若 Labubu 下滑止不住，现价仍贵；若星星人接棒，现价便宜。

## 6. 风险与跟踪

### 6.1 主要风险

- **IP 集中**：THE MONSTERS 仍占 26%，Labubu 热度继续下降会拖累整体。
- **海外执行**：线上 -40% 至 -59%，本地团队、供应链、文化理解都是挑战。
- **库存**：201 天周转，若销售不及预期，减值/折扣会压低毛利。
- **竞争**：52TOYS、TOP TOY、名创优品、万代/乐高；IP 争夺与渠道内卷。
- **监管/舆论**：盲盒诱导消费、未成年人保护、二手炒作；政策风险。

### 6.2 跟踪清单

- THE MONSTERS 月度/季度收入与二手价格；Labubu 是否止跌。
- 星星人、Molly、Skullpanda 等新 IP 收入占比与增速。
- 海外分区域收入、线上/线下结构、门店坪效。
- 库存周转天数与折扣率；经营现金流/净利。

## 7. 结论

**合理偏低，置信度 低。** Labubu 退潮不是终点，但 2026H1 证明 IP 周期比市场想的更快；现价合理偏低，前提是星星人等新 IP 接棒。

- 现价 HK$128.70（¥110.17）；基准价值 ¥119 / HK$139；概率加权 ¥124 / HK$144；20% 安全边际价 ¥95.3 / HK$111.3。
- 现价相对基准 -7.5%；乐观 ¥203 / HK$237，悲观 ¥53.4 / HK$62.4。
- 市场隐含 10 年收入 CAGR 4.7%，基准 5.1%。
- 本结论基于公开数据与明确假设；不是个性化买卖建议，也不构成投资建议。

### 7.1 与市场共识的差异

- **市场共识：** 市场假设 Labubu 退潮是永久性的、新 IP 无法接棒；我们认为星星人等 IP 可以部分对冲，但不确定性很高。
- **我们的差异：** 我们更关注下行风险与估值的安全边际，而不是基准情景的完美兑现。
- **验证点：** 未来 2–4 个季度的收入增速、利润率与现金流，是判断谁对谁错的关键。
