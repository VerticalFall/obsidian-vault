## 方法与边界
指数版保留了公司版的三条纪律：正常化盈利、至少两种估值证据、显式安全边际；去掉了不适用于指数的“管理层/护城河/八问”，替换为“历史分位+盈利增长+利率/ERP”三锚。

**重要：** 各指数PE口径不同（中证动态PE、第三方PE、远期PE），横向比较请看“距中枢”和ERP；2027E增速与PE带是假设，不是预测承诺。本文件夹不是买卖建议。
