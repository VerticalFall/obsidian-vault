# Excel与图表交付规范

仅用户要文件/图表时使用。尊重给定模板；完整研究可用下表，小任务按需合并，不硬建空表。

| 表 | 内容 |
|---|---|
| 一图流 | 怎么赚钱、研究结论、价格/财报日期、关键指标、价值区间、三项风险；需要图表时集中展示关键图 |
| 生意与护城河 | 分部/地区/客户、竞争优势及反证、管理层资本配置 |
| 财务与现金流 | 五年＋最新可比期、利润质量、应收存货、开支、债务和可比指标 |
| 分红与股东回报 | 年度/LTM/预测DPS、普通/特别、覆盖、回购注销、增减持稀释；不适用可合并 |
| 估值与假设 | 唯一输入区、依据、三情景过程、安全边际和敏感性 |
| 风险与跟踪 | 风险路径、指标触发、后续核查；持有问题四项检验 |
| 数据与来源 | 原始值、期间/单位/口径、定位、调整、缺失；多时另分原始数据和来源 |

一图流不只放目标价，要看见生意、盈利现金、股东回报和风险；无图表时保留一页摘要。

## 数据与公式

原始数据和假设分开，输入→计算→估值→摘要/图表，不多处手填同一数。输入浅蓝/蓝字、公式深色、来源引用绿色、假设浅黄、风险浅红，并附图例；颜色辅助文字。

衍生值尽量用Excel公式，关键参数可编辑并说明更新位置；跨表引用加引号。使用环境支持的常用公式，不伪造计算缓存。缺失、不适用与0分开，不能用 `IFERROR(...,0)` 掩盖错误。历史实际、TTM和预测清晰标记。

文件本身有研究日、财报截止日、价格日、市场、币种、单位及来源，离开聊天仍可理解。

## 图表（用户需要时）

选能回答问题且数据齐备的3—5张，不凑数，缺数据就减少并说明。

| 问题 | 推荐 | 核对 |
|---|---|---|
| 业绩变好了没？ | 年度趋势＋最新同比；量级不同分图或标明双轴 | 不把全年、半年、TTM连成假趋势 |
| 利润变现金了吗？ | 非金融利润/CFO/FCF并列，附口径差异 | CFO合并、利润归母的差异须说明 |
| 分红稳吗？ | 普通/特别DPS柱图＋派息率或覆盖图 | 实施、公告、预测分开 |
| 价格贵吗？ | 情景价值柱图＋现价参考线；方法对比 | 同币种同每股单位，情景非收益承诺 |
| 最大变量？ | 敏感性热力表/驱动对比 | 每格真计算，不仅改色 |
| 银行好转没？ | NIM、信用成本、不良、资本分图 | %/bp分清，不套工业CFO |

分部结构优先横向条形/堆积图，不用3D装饰。不编造历史股价；价格/含息曲线须有真实数据及调整说明。

优先原生可编辑图表，引用真实底表范围并随重算更新；注明标题、单位、期间、图例，缺失不画零，预测用不同颜色/虚线。柱图通常从零起，截断轴显著说明；不能遮挡表格。新增期间要扩展图表范围并核对。图片只作补充并标“静态”、日期及更新办法。

## 可读性

中文易读字体，标题约16—20pt、正文10—12pt，冻结表头，长文换行，列宽/行高足够，金额百分比格式统一。展示单元格默认水平垂直居中，长说明可左对齐。不堆小字、大空白和碎片合并。网址独立列或超链接，别挤压摘要。

## 验证

1. 核对来源、单位、期间、股权/企业价值桥接和估值勾稽。
2. 用实际可用计算引擎重算，检查 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?`、`#NUM!` 等。预期缺失单独标记。
3. 改一个重要参数重算，核对估值、摘要、图表联动，再恢复。设置“打开时重算”不算已验证。
4. 有预览/渲染能力时逐表检查裁切、图表、缩放；无能力注明未做，不能凭文件存在声称通过。
5. 保存重新打开，核对表名、公式、图表及来源链接。

无重算能力可交付含公式文件，但文件与回复显著标“尚未重算，请在表格软件打开后重算”，关键结论用独立算术复核。图表依赖未计算缓存时说明预览可能无数据，需打开重算后检查。无文件能力交付分表数据、公式、图表说明及必要脚本，不能声称已交付xlsx。
