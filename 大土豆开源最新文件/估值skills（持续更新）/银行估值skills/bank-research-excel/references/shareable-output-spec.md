# 传播版输出规范

## 1. 输出组合

默认只交付四个成品：

1. 两页简版 Excel；
2. 总榜与四类榜 PNG；
3. 三类投资者榜 PNG；
4. 简短的数据日期与免责声明。

用户要求查看全部银行明细时，再增加五页分类榜 Excel。禁止把检查日志、逐页预览、缓存图片和中间数据放进传播文件包。

## 2. 两页简版 Excel

工作表固定为：

1. `总榜与四类榜`
2. `三类投资者榜`

### 总榜与四类榜

- 顶部写清“股价截至”和“财务数据截至”，不可只写一个日期。
- 展示基准总榜前三名、总榜前十名和四类银行各自领先者。
- 总榜至少包含：排名、银行、代码、银行类别、基准研究分、盈利质量分、风险资本分、估值分、股息分。
- 四类银行统一为四大行、股份行、城商行、农商行；分类规则需固定且可说明。
- 用一句大白话解释：基准分是固定尺子，适合横向比较，不代表个性化买卖建议。

### 三类投资者榜

- 同页并列展示稳健收息、均衡复利、进取修复三组前五名。
- 明示三类画像的固定权重和风险上限。
- 同时保留每家银行的基准研究分，避免把“适合某类人”误读成“绝对更好”。
- 如期限或回撤承受力不满足前置条件，显示“不适用”，不能强行给出画像榜。

## 3. 五页分类榜

用户要求全部明细时，工作表固定为：

1. `总榜`
2. `四大行`
3. `股份行`
4. `城商行`
5. `农商行`

每页保留银行代码、类别、基准研究分、四项基础分和三类画像分。总榜使用固定基准研究分排序；分类页不得另改权重。

## 4. 两张传播图

- 推荐竖版长图，宽度至少 1080 像素，手机端无需放大即可读主要排名。
- 第一张：总榜前三、总榜前十、四类银行领先者、阅读提示。
- 第二张：三类投资者前五、固定权重、风险上限、公正性说明。
- 不显示 Excel 行列标题、网格线、文件路径、检查信息和中间公式。
- 标题、日期、排名、分数和免责声明不可被裁切。
- 颜色只承担信息层级，不单独承担“好/坏”含义；保证黑白截图仍能辨识。

## 5. 公正性边界

传播版必须并列呈现两套概念：

- **基准研究分**：固定权重、统一尺度，用于保持量化的横向公正性；
- **画像匹配分**：固定预设下的适配排序，用于回答不同投资者更看重什么。

问卷不能改变财务事实、基础分和基准估值。任何画像榜都应标注“适配度，不是内在价值，也不是买卖建议”。

## 6. 质量门槛

- 银行数量、代码、分类和得分与底层排名表逐项一致；
- 总榜与三类画像榜的排序规则固定；
- 所有得分在 0–100 之间，无空白关键字段；
- 公式错误为零；静态传播快照可以不保留公式和图表对象；
- 两张图片均完成可视检查；
- 文件名带市场日期，正文同时披露市场日期和经营数据日期；
- 成品目录尽量控制在 2 MB 内。
