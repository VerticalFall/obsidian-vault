# FCF/EV 自由现金流估值 Skill（煤炭行业生产版）

## 核心铁律：FCF 锁死，禁止 TTM

**FCF 是锁死的，只有市值可以变。** 所有人算出来必须是同一个数。

| 数据   | 来源            | 更新频率             | 为什么          |
| ---- | ------------- | ---------------- | ------------ |
| FCF  | FY2025 年报，硬编码 | 半年一次（年报/中报发布后升级） | 让每个人算出来一样    |
| 总负债  | 最新季报          | 季报发布后升级          | 统一锚点         |
| 货币资金 | 最新季报          | 季报发布后升级          | 统一锚点         |
| 总市值  | 实时行情          | 每天变              | 估值本来就是看今天的价格 |

> **严禁使用 TTM。** TTM 会随你哪天算而变化——张三一月算、李四八月算结果不一样，这个 Skill 就没法复用。FCF 永远用 FY2025 完整年度。FY2025 年报出来前用 FY2024，出来后切 FY2025。全天下只有一个版本。

## 行业基准

| FCF/EV      | 判断                   |
| ----------- | -------------------- |
| > 3.8%      | 低估 🟢                |
| 2.8% ~ 3.8% | 合理 🟡                |
| < 2.8%      | 偏贵 🔴                |
| FCF 为负      | 因子不适用 ⚪（高 capex 扩张期） |

> 注意：原草稿曾用「>5% 为低估」的非官方口径。本生产版严格采用源达回测的 3.3% 基准 + 3.8%/2.8% 三档，与因子研究一致。

---

## 公式

```
FCF  = 经营性净现金流（FY2025 年报） − 资本支出（FY2025 年报）
EV   = 总市值（实时） + 总负债（最新季报） − 货币资金（最新季报）
FCF/EV = FCF ÷ EV × 100%
```

## 数据拉取工作流

### 第 1 步：确认范围

- 用户指定公司 → 单只计算
- 用户说"一键对比" → 从 `references/company-data.md` 读取已锁 FCF，拉取最新市值和资产负债表
- 用户说"更新估值表" → 若下一财报季已发布，统一升级 FCF 与资产负债表（半年一次，不是日常）

### 第 2 步：拉取数据

**已有锁死 FCF 的公司：** 跳过 FCF 拉取，只拉当前市值 + 最新季报的「负债合计」「货币资金」。

**新公司（FCF 待拉取）：** 分两轮 WebSearch。

- 第一轮（结构化）：`"[公司名] [代码] [年度]年报 经营活动现金流量净额 总负债 货币资金 总市值"`
- 第二轮（capex，最容易错）：`"[公司名] [代码] [年度]年报 现金流量表 购建固定资产无形资产长期资产支付 全年"`

**🚫 资本支出数据源黑名单：**

- ❌ 任何标注「自由现金流量」的字段（第三方黑箱，已验证不可靠）
- ❌「投资活动产生的现金流量净额」（含理财/收回投资，非 capex）
- ❌「资本性支出」（管理层口径，可能含非现金项）

**✅ 唯一合法源：现金流量表「购建固定资产、无形资产和其他长期资产支付的现金」（年度合计）**

### 第 2.5 步：强制验证 capex

- **验证 A**：投资活动 CF 净额(取绝对值) ≥ 购建固定资产支付现金，否则字段混淆，重搜。
- **验证 B（Q4 异常）**：若只拿到 Q1-Q3 累计 capex，**禁止线性外推**。Q4 常集中支付工程款。山西焦煤 2025 年 Q4 单季 capex 13.29 亿 > Q1-Q3 合计 12.25 亿，外推会严重低估 capex。

### 第 3 步：取市值

市值优先用实时行情（westock-data / 搜索）。A+H 双重上市默认用 **A 股市值**。

### 第 4 步：计算 & 判断

按公式算 EV、FCF/EV，套用上方三档基准。

## 🚨 常见错误 & 防坑指南

1. **不减资本支出，用经营 CF 当 FCF**：最致命。中煤经营 CF 298 亿减 capex 后仅 80 亿，不减会虚高 3-4 倍。
2. **用「投资活动 CF 净额」代替 capex**：神华投资活动净额仅 -218 亿，实际 capex 484 亿，差 2.2 倍。
3. **信第三方「自由现金流量」字段**：公式不透明，已验证不可靠，只看现金流量表原文。
4. **前三季度 capex 线性外推全年**：Q4 工程款集中，山西焦煤 Q4 单季超 Q1-Q3 合计。
5. **A/H 数据混用**：兖矿 A 股经营 CF 194.85 亿 vs H 股 166.40 亿（CAS vs IFRS），默认 A 股。
6. **FCF/EV > 10%**：先自查①减了 capex②全年非单季③净现金使 EV 极小（晋控 11.49% 真实，因净现金状态）。
7. **硬编码 FCF 与实时脱节**：FCF 锁死 FY2025，但市值/EV 必须实时更新；勿把旧市值当新数。

## 行业批量计算

用户要求「煤炭行业整体估值」时：

1. 用 `westock-data` 取板块成份股，按市值排序，优先头部 10-15 只（覆盖 90%+ 市值）
2. 每只独立按上述流程算
3. 汇总区分「市值加权 ΣFCF/ΣEV」与「等权均值」，说明权重股扭曲
4. FCF 为负的单独标「不适用」
5. 组合真实收益率用 **ΣFCF/ΣEV**（非简单均值），例：9 只完整股 = 3.46%（≈基准），剔除神华 = 4.56%

## 使用限制

- 仅适用于 **A 股煤炭行业大盘股**（沪深300成分股）
- 中小盘煤炭股回测无效（中证1000 多空年化 -9.27%）
- FCF 锁死至下一份年报，日常勿"更新"FCF 数字
- 因子非越高越好，极端值叠加股息率、负债结构、煤价走势综合判断
- 不构成投资建议
