# 大土豆开源最新文件 · 总架构

> 一句话：这里不是一个统一估值模型，而是 **四条研究生产线 + 两个成品仓库 + 一个输出库**。

> 本文件只做三件事：**什么时候用哪套、哪套是权威、输出应该长什么样**。它不替代各 skill 的方法论文档，只做导航和约束。

## 2. 什么时候用哪套

### 2.1 决策树

```text
你的问题是什么？
│
├─ 这家公司是不是好生意、值多少钱？
│   ├─ 是银行/保险？ → 银行估值skills
│   └─ 其他行业？     → 巴菲特skills-改良版（完整研究）
│
├─ 只想快速比较煤炭股谁便宜？
│   └─ 煤炭自由现金流估值模型（FCF/EV 快筛）
│
├─ 煤炭/石油要做完整周期估值？
│   └─ 红利专区/A股煤油周期估值系统
│
├─ 这家公司/这个板块的红利能不能持续？
│   └─ 红利专区/红利可持续性评分表 + 00-红利研究框架
│
├─ 红利组合怎么配、和 10Y 比有没有性价比？
│   └─ 红利专区/红利可持续性评分表 → 总回报 + 组合监控
│
├─ 今天市场热不热、明天怎么走？
│   └─ 韭菜指数-v4
│
└─ 只想看以前做过的成品？
    └─ 个股研究专区 / 输出历史目录（归档，不是权威）
```

### 2.2 场景对照表

| 场景 | 首选 | 配合使用 | 不要用 |
|---|---|---|---|
| 首次研究一家非金融公司 | 巴菲特完整研究 | 行业可比、宏观/利率背景 | 直接套 DCF 不看生意 |
| 银行股 | 银行估值skills | 巴菲特八问做定性补充 | 工业 FCFF、EV/EBITDA、工业 ROIC |
| 保险股 | 巴菲特保险插件 + 个案 | 银行 skill 的 PB–ROE/DDM 思路 | 工业 FCFF |
| 煤炭股快速排雷 | 煤炭 FCF 模型 | 中证红利板块位置 | 把 FCF/EV 当完整估值 |
| 煤炭/石油完整周期 | 红利专区煤油模型 | 商品价格、产量、资本开支 | 用单年利润年化 |
| 红利单票深度 | 巴菲特完整研究 | 红利评分表、总回报表 | 只看股息率 |
| 红利板块位置 | 中证红利量化更新 | 红利评分表做个股验证 | 把相对排名当绝对估值 |
| 红利组合 | 红利评分表 → 组合监控 | 10Y、税率、汇率、相关性 | 单票标签直接拼组合 |
| 市场情绪/次日情景 | 韭菜指数v4 | 无 | 用情绪指标做公司估值 |
| 查看历史成品 | 个股研究专区/输出 | 总索引 | 把旧 Excel 当现行规范 |

## 3. 权威矩阵

> 原则：**方法论 skill > 专项框架 > 单份报告 > 历史成品**。冲突时，上位覆盖下位；历史成品不反向覆盖 skill。

| 问题 | 权威来源 | 优先级说明 | 不应使用 |
|---|---|---|---|
| 通用公司研究流程、八问、证据账本 | `巴菲特skills-改良版/skills/buffett/SKILL.md` + `references/09–11` | 跨行业总规范 | 单份旧报告、个股专区 Excel |
| 银行专属指标、六种估值、四维评分 | `银行估值skills/bank-research-excel/SKILL.md` + `references/` | 银行领域覆盖巴菲特行业插件 | 工业 FCFF、EV/EBITDA |
| 煤炭快速 FCF/EV 比较 | `煤炭自由现金流估值模型/SKILL.md` | 仅快筛；不覆盖完整周期估值 | 作为完整估值结论 |
| 煤炭/石油完整周期估值 | `红利专区/A股煤油周期估值系统.xlsx` | 完整模型覆盖快筛 | 用快筛替代完整模型 |
| 红利可持续性、总回报、组合层 | `红利专区/00-红利研究框架.md` + `红利可持续性评分表.xlsx` | 红利专项最高规范 | 只看股息率/连续分红 |
| 中证红利板块位置 | `红利专区/10.13中证红利2026量化更新.xlsx` | 截至该文件数据日的横截面 | 当作绝对估值或未来收益预测 |
| 市场情绪/次日情景 | `韭菜指数-v4（可直接跑）/SKILL.md` + `references/scoring-v4.md` | 情绪领域唯一权威 | 用于公司估值 |
| 历史成品/案例 | `个股研究专区/`、`输出/` 历史目录 | 仅归档、参考 | 作为现行模板或权威结论 |

### 3.1 三个容易混的边界

1. **巴菲特 skill ≠ 所有行业都直接用 DCF。** 银行用 RI/PB–ROE/DDM；煤炭用中周期现金利润/资源 NAV/股息；公用事业用 FCFF/DDM；控股用 NAV/SOTP。
2. **煤炭 FCF 模型 ≠ 煤炭完整估值。** 它只回答“按 FCF/EV 谁更便宜”，不回答资源禀赋、长协、一体化、资本开支周期。
3. **中证红利量化 ≠ 红利个股评分。** 它是 100 只成分、14 个板块的横截面相对排名，不是单票绝对估值。

## 4. 输出契约

### 4.1 通用公司研究（巴菲特 skill）

目录：

```text
输出/{市场}/{代码}-{YYYY-MM-DD}/
├── {公司}-{代码}-巴菲特框架研究-{YYYY-MM-DD}.md
├── {代码}-估值模型-{YYYY-MM-DD}.xlsx
├── {代码}-估值模型-{YYYY-MM-DD}.pdf
├── {代码}-估值仪表盘-{YYYY-MM-DD}.png
├── {代码}-估值仪表盘-{YYYY-MM-DD}.svg
└── {代码}-估值仪表盘-{YYYY-MM-DD}.html
```

Excel 表结构：

- **前 3 张固定**：一图流、投资结论、估值系统。
- **后 2 张固定**：风险与跟踪、数据与来源。
- **中间按行业加表**：生意与护城河、财务与现金流、分红与股东回报、估值敏感性、同业比较等。
- 银行走 `银行估值skills` 的 11 表规范，不套用本模板。

### 4.2 银行研究

- 传播版：2 页 Excel + 2 张 PNG。
- 完整版：11 张表，顺序固定：一图流、投资者画像、投资结论、估值系统、估值敏感性、股息估值、财务十年、资产质量、同业比较、巴菲特框架、数据与来源。
- 必须保留：基准分 vs 投资者画像分、四维评分、DDM 防御价值、ROE/Ke/g 敏感性。

### 4.3 煤炭快筛 vs 煤油完整模型

| 输出 | 形态 | 用途 |
|---|---|---|
| 煤炭 FCF 快筛 | 一张横向比较表 | 快速排雷、初筛 |
| 煤油完整模型 | Excel 多表（估值总览、参数、前瞻、模型、周期归一化、原始数据） | 完整周期估值、情景与安全边际 |

### 4.4 红利研究

- `红利专区/00-红利研究框架.md`：方法论与边界。
- `红利专区/红利可持续性评分表.xlsx`：评分总表、分红安全、金融红利、质量防御、总回报、组合监控、数据与来源、检查。
- `红利专区/红利可持续性评分表.pdf`：同一工作簿的打印版（13 页），用于评审与归档。
- 单票深度仍用巴菲特完整研究；红利评分表不替代单票报告。

### 4.5 韭菜指数

- HTML + PNG 长图。
- 数据 MD（L2/L3 证据）。
- 必须包含：五个温度计、数据层级、验证表、免责声明。

### 4.6 归档

- `个股研究专区/` 与历史 `输出/` 只做案例库。
- 新增研究不再复制旧 Excel 结构，按本文件第 4 节输出契约执行。

## 5. 统一评级与元数据

### 5.1 五级评级

| 评级 | 安全边际 `1 − 现价/基准价值` | 含义 |
|---|---:|---|
| 便宜 | > +20% | 价格显著低于基准价值 |
| 合理偏低 | +5% ~ +20% | 有一定安全边际 |
| 合理 | −5% ~ +5% | 接近基准价值 |
| 合理偏贵 | −20% ~ −5% | 高于基准，安全边际不足 |
| 昂贵 | < −20% | 显著高于基准价值 |

> 质量分与估值评级分开：一家公司可以是“质量 85 分 / 估值昂贵”，也可以是“质量 55 分 / 估值便宜”。不要用一个词同时表达两件事。

### 5.2 置信度

| 置信度 | 使用条件 |
|---|---|
| 高 | 硬数据完整、行业稳定、两种以上方法结论收敛 |
| 中高 | 硬数据为主、方法大体收敛、少量关键假设 |
| 中 | 软数据/周期假设较多、方法有分歧 |
| 中低 | 周期或结构不确定性高、方法分歧大 |
| 低 | 数据缺口大、结论对单一假设敏感 |

### 5.3 报告元数据块

每份研究 MD 顶部统一放：

```text
> 报告日：YYYY-MM-DD
> 价格日：YYYY-MM-DD
> 数据截止：YYYY-MM-DD
> 取数日：YYYY-MM-DD
> 评级：便宜 / 合理偏低 / 合理 / 合理偏贵 / 昂贵
> 质量分：0–100（可选）
> 置信度：高 / 中高 / 中 / 中低 / 低
> 框架版本：buffett-vX.Y.Z / bank-vX.Y.Z / dividend-vX.Y.Z
```

## 6. 数据与证据标准

1. **每个关键数字有来源**：来源名、发布方、链接/附件、发布日、期间、页码/表格、原始值+单位、归一化值、状态。
2. **四个日期分开**：报告日、价格日、数据截止日、取数日。
3. **TTM 规则**：不得用半年 × 2；必须有明确计算式。
4. **追溯调整**：并表、重组、会计政策变更必须标注，不能直接拼历史。
5. **股本口径**：稀释后股本；少数股东、永续债、优先股单独扣除。
6. **分红口径**：年度/ LTM / 预测分开；普通股息与特别股息分开；已实施/已公告/假设分开。
7. **跨市场**：币种、汇率、税率、上市地、股份类别、财年必须写清；H 股折价、ADR、预扣税单独处理。
8. **数据状态**：硬数据 / 软数据 / 假设 / 待核，四类标签必须可见。

## 7. QA 检查清单

每份输出交付前逐项检查：

- [ ] 文件齐全：MD、XLSX、PDF、仪表盘 PNG/SVG/HTML。
- [ ] 链接可点击：总索引、观察清单、报告内链无死链。
- [ ] 数字一致：MD、Excel、PDF、仪表盘的关键结论一致。
- [ ] 公式无错：Excel 无 `#REF!`、`#VALUE!`、`#DIV/0!`。
- [ ] 日期新鲜：价格日、数据截止日、取数日明确；过期数据有标记。
- [ ] 评级一致：五级评级与安全边际数值对应。
- [ ] 口径一致：TTM、股本、少数股东、EV、FCF 定义一致。
- [ ] 无残留：无中间 HTML、旧版本 PDF、临时文件。
- [ ] 免责声明：明确“不构成投资建议”。
