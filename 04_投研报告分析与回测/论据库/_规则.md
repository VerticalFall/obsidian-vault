# 论据拆解规则

> 这套规则解决一个问题：**怎么让"事后复盘"不变成"事后讲故事"。**
> 答案是：在结果发生之前，就把"什么算对、什么算错"写死。

---

## 一、五步拆解协议

### 第 1 步 · 一句话论点

用一句能判真假的话，写出"这家机构认为未来 12 个月会发生什么"。
不能是"看好公司发展"这种无法判死的句子。

❌ 不好：「公司长期成长逻辑清晰，维持买入」
✅ 好：「公司靠加盟扩张把门店数从 400 家推到 600 家，同时单店收入不下滑，因此 2026 年营收增速回到 20% 以上」

### 第 2 步 · 论据池

把正文里的"因为 X 所以 Y"逐条抽出来，编号。

- 一条论据一行，不复述原文句子，压成因果结构
- 标类型：需求 / 价格 / 产能 / 份额 / 政策 / 成本 / 新品 / 并购 / 财务质量 / 估值
- **论据排序按它在原文里的分量**，不是按对你来说的吸引力

### 第 3 步 · 可证伪性判定（这一步是整套系统的命门）

对每条论据问一句：**到期那天，我用哪个数字判它是错的？**

| 判定 | 含义 |
|---|---|
| 可证伪 | 能写成一个带阈值的可观测指标 |
| 部分可证伪 | 有方向但没阈值，只能判"更好了/更差了" |
| 不可证伪 | 是"举措""战略""协同""生态"这类词，永远无法判死 |

**不允许跳过。** 写不出判据就填"不可证伪"——这不是偷懒，这是发现。
一篇报告里不可证伪的论据占比，本身就是"这篇报告值不值得读"的量化指标。

### 第 4 步 · 逻辑缺口

从论据到结论之间，作者跳过了哪一步。

制造业/成长股最常缺的是三跳中的后两跳：
> 产能落地 → **卖得掉** → **价格不塌**

消费/服务股最常缺的是：
> 门店/用户增长 → **单店产出不下滑** → **费用不失控**

写不出缺口，说明你还没读懂这篇报告。

### 第 5 步 · 到期打分（结果出来之后，且只做两件事）

**机械分（脚本算，不许人改）**：区间收益、相对基准超额、目标价是否触及、EPS 是否达成。

**定性分（逐条判）**：每条论据 → 成立 / 部分成立 / 不成立，并归因到下面五类之一：

| 失效机制 | 含义 |
|---|---|
| 需求没来 | 终端需求不及预期 |
| 价格崩了 | 量到了但价格/毛利塌了 |
| 竞争提前 | 别人先做成了，或被替代品抢走 |
| 自己算错了 | 财务模型假设本身有问题 |
| 就是个故事 | 论据本就不可证伪，涨跌与逻辑无关 |

## 二、反前视偏差红线（违反即作废）

1. **只能用报告发布日及之前的公开信息**做拆解。不能用"后来涨了/跌了"反推"当时这条论据强不强"。
2. **不许改历史判据**。到期发现判据写得不合理，也不能改——只能新开一条"判据失效"记录。理由：改了就不是预注册了。
3. **看不到结果时也要写**。还没到期就先写完论据池和证伪条件，到期再填分。这是整个系统唯一的防作弊机制。

## 三、打分口径（全系统统一）

| 口径 | 规则 | 为什么 |
|---|---|---|
| 建仓 | 报告日后的第一个交易日收盘 | 报告多在开盘前发布，T 日收盘已有反应，T+1 更保守 |
| 价格 | 前复权 | 分红送转不会制造假跌 |
| 期限 | 12 个月为主，另记 1/3/6 个月 | 卖方常不写时间窗，用固定窗才有可比性 |
| 基准 | 沪深300（对照口径：中证500 / 中证1000 / 行业指数） | 不与基准比的"命中率"没有意义 |
| **主指标** | **中位数超额 + 跑赢率** | 均值被右尾拉爆：2025 年 12 个月偏多组均值 +14.76%、中位 −10.98% |
| 目标价 | 只作辅助 | 2025 年实测仅 7.7% 的报告给目标价 |

## 四、字段说明（claim 文件 front matter）

| 字段 | 写入方 | 说明 |
|---|---|---|
| `claim_id` / `info_code` | 脚本 | 唯一标识 |
| `frozen_at` / `body_sha256` | 脚本 | 冻结时点与原文哈希，用于证明"没被事后改过" |
| `px_at_publish` / `eps_*` / `rating*` / `target_price` | 脚本 | 发布当时的口径快照 |
| `direction` / `horizon_months` | 脚本（可改） | 方向与期限 |
| `status` | 人工 | 待拆解 / 已拆解 / 待核 / 已复盘 |
| `score`（正文 AUTO 区块） | 脚本 | 机械成绩，每次运行覆盖重算，人手不动它 |

## 五、命令

```powershell
# 冻结新一批样本（--max-publish 保证 12 个月已到期）
python scripts/step4_freeze.py --detail "数据/03_回测结果/backtest_沪深300_20261017_样本明细.jsonl" --n 5 --max-publish 2025-09-15

# 只冻结指定报告
python scripts/step4_freeze.py --info AP202509151744330127

# 到期机械打分 + 刷新看板
python scripts/step5_score.py
```

运行前先设编码，否则中文 print 会炸：

```powershell
$env:PYTHONUTF8="1"; $env:PYTHONIOENCODING="utf-8"
```

## 六、当前缺口（诚实记录）

| 缺口 | 影响 | 补法 |
|---|---|---|
| 没接财报/公告数据 | 论据里"营收/净利/毛利率/EPS 实际值"类判据无法核 | 接东财财报接口或巨潮公告 |
| 正文只有摘要（约 1,100–1,600 字） | 细节论据抽不到，只能拿到主干 | 下 PDF：`pdf.dfcfw.com/pdf/H3_{info_code}_1.pdf`，中文字体需 CID 解码 |
| 样本量小 | 5 条 claim 只能示范方法，不能下结论 | 按周批量冻结，先攒到 100 条 |
