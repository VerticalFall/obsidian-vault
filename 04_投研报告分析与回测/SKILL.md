# 研报速读 Skill

把券商研报从「1 小时看完只记住 20%」压到「5 分钟拿到可对比的结构」。

核心做法：**脚本负责确定性抽取，模型负责判断**。数字、分页、段落定位交给脚本，绝不靠模型"读一遍然后回忆数字"；投资逻辑、评级理由、风险解读才由模型来做。

## 1. 适用与不适用

**适用**
- 券商/投行个股研报：深度报告、业绩点评、首次覆盖、跟踪报告
- 行业深度报告（有明确标的或行业数据）
- 一次读多份、需要横向对比同一公司的多份研报

**不适用**
- 招股书、年报全文（篇幅结构完全不同，用文档处理类技能）
- 纯公告、新闻稿（信息量太低，直接读）
- 扫描件图片型 PDF（无文字层，需先 OCR）

## 2. 五条规则（输出铁律）

### 规则 1 · 结构：10 段，顺序固定
投资要点 → 业绩 → 业务 → 行业 → 财务 → 估值 → 风险 → 催化剂 → 目标价 → 评级。
每段 1-3 句，全文 500-800 字。**段落顺序不可调换**，这样多份研报才能逐段对比。

### 规则 2 · 数据：无单位即无效
必抽指标：营收、净利、毛利率、ROE、PE、PB（有则加 EPS、负债率、目标价）。
每个数字必须带 **单位 + 同比/环比**。写成「营收 100」是废数据，「营收 100 亿元（+20% YoY）」才是有效数据。

### 规则 3 · 估值：至少一种方法，必须有偏差
至少用一种：PE / PB / DCF / EV/EBITDA。
必须给出 **当前估值 → 合理估值 → 偏差% → 目标价**。只给目标价不给算法，等于没给。

### 规则 4 · 风险：四类全覆盖，缺一类要明说
行业风险 / 政策风险 / 公司风险 / 估值风险，每类 1-2 句。
**原研报没写的类别，标注「⚠️ 原文未明确提及」，绝不替他补。** 缺项本身是信息。

### 规则 5 · 输出：5 段格式
摘要 / 关键点（10 条，1 行 1 条）/ 估值 / 风险 / 建议。
建议必须是买入 / 增持 / 持有 / 减持 / 卖出之一，且附理由（估值偏差、业绩超预期幅度等）。

## 3. 六步工作流

```bash
# 技能目录 = 本 SKILL.md 所在目录（见 skill 列表的 base_dir）
SK="<base_dir>"

# Step 1-2: 读 PDF + 按关键词定位 10 段 + 抽指标 + 归 4 类风险
python3 "$SK/scripts/extract_report.py" report.pdf -o /tmp/sk.json

# 页数多时可只读关键页（封面+投资要点+估值+风险段通常在前 20 页）
python3 "$SK/scripts/extract_report.py" report.pdf --pages 1-20 -o /tmp/sk.json

# 拿到骨架后先自检，再决定要不要读全文
#   看 sections_missing：缺了哪几段
#   看 metrics：哪些数字没抽到（空 = 需回原文找）

# Step 3: 需要原文细节时，单独取全文（占 token，按需使用）
python3 "$SK/scripts/extract_report.py" report.pdf --full-text -o /tmp/sk_full.json

# Step 4-6: 渲染 5 段摘要
python3 "$SK/scripts/render_summary.py" /tmp/sk.json -o /tmp/summary.md
```

**脚本只给骨架，必须由你补判断层**：

| 脚本给不了，你要补 | 依据 |
|---|---|
| 「投资要点」的一句话核心逻辑 | 读 `sections.summary` 后自己压缩到 100 字内 |
| 评级理由 | 交叉核对「估值偏差」与「业绩增速」是否一致 |
| 风险的真实含义 | 把原文风险句翻译成对股价的传导路径 |
| 交叉验证 | 业绩高增却给减持？数字与结论矛盾必须指出 |

## 4. 交叉验证清单（防幻觉，逐条过）

输出前自查，任何一条不通过就回原文核对：

1. **单位**：每个数字都有单位吗？（亿元/万元/%/x）
2. **同比**：增长类数字都有 YoY 吗？没有就标「原文未给同比」。
3. **估值闭环**：当前估值、合理估值、目标价三者是否自洽？
4. **评级有理**：评级能否被「估值偏差 + 业绩增速」解释？
5. **风险完整**：四类是否都点到？缺失的有没有标注？
6. **逻辑一致**：业绩增长与评级方向是否矛盾？（增长 25% 却给减持 = 必须解释）
7. **不编数**：有没有出现原文没有的数字？（一个都不许有）

## 5. 五个坑（原文作者踩过，直接避开）

| 坑 | 表现 | 修正 |
|---|---|---|
| 数据失真 | 「营收 100」不知单位 | 强制带单位 + 同比 |
| 估值不严谨 | 目标价凭感觉 | 至少一种方法 + 偏差% |
| 风险遗漏 | 只报 1 类风险 | 四类各 1 句，缺项标注 |
| 评级机械 | 永远是「买入」 | 必附理由，可给减持 |
| 上下文割裂 | 业绩好却给减持，不解释 | 交叉验证后再落笔 |

## 6. 输出模板

```markdown
# 研报速读：<公司/行业> · <券商> · <日期>

## 【摘要】
一句话核心逻辑（≤100 字）

## 【关键点】
1. 营收：XX 亿元（+XX% YoY）
2. 净利：XX 亿元（+XX% YoY）
3. 毛利率：XX%（同比 ±XXpct）
4. ROE：XX%（行业均值 XX%）
5. 估值：PE XXx（行业 XXx，折/溢价 XX%）
6. 业务：<主营 + 占比>
7. 行业：<规模 + 增速 + 格局>
8. 财务：<负债率 / 现金流>
9. 风险：行业 / 政策 / 公司 / 估值
10. 评级：<买入/增持/持有/减持/卖出>

## 【估值】
当前 PE XXx · 合理 PE XXx（偏差 ±XX%）· 目标价 XX 元（±XX%）· 评级 XX

## 【风险】
- 行业：<1 句>
- 政策：<1 句>
- 公司：<1 句>
- 估值：<1 句>

## 【建议】
<评级> + 理由（估值偏差 / 业绩超预期幅度 / 催化剂）
```

## 7. 多份研报横向对比

读多份时，先各自输出上面模板，再追加一张对比表。**只对比同一指标**，缺失的留「—」不要填：

| 指标 | 券商A | 券商B | 券商C |
|---|---|---|---|
| 评级 | | | |
| 目标价 | | | |
| 营收增速 | | | |
| PE | | | |
| 核心分歧点 | | | |

最后一行「核心分歧点」是横向对比的价值所在：**券商之间在哪里不一致**，比他们一致同意什么更有用。

## 8. 环境

脚本依赖 `pdfplumber`（纯文本输入不需要）。缺失时安装：

```bash
pip install --user pdfplumber
```

若装不上，用其他方式把 PDF 转 txt，再用 `--text` 参数传入。

## 9. 定位边界

这是**速读**工具，不是投资决策工具。产出用于快速判断"这份研报值不值得深读、结论是什么"，不构成任何投资建议。研报本身的结论可能带有卖方立场（多数券商极少给卖出评级），**评级分布本身就是需要读出的偏差信息**。
