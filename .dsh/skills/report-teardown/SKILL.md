# report-teardown · 卖方研报拆解与复盘

> 定位：**把"事后讲故事"变成"预注册 + 机械判分"**。
> 全部规则以 `04_投研报告分析与回测/论据库/_规则.md` 为准；本文件是操作手册。

## 什么时候用

- 用户拿到一份研报，想知道它到底在赌什么
- 一批 claim 到期了，要把"论据成立 / 不成立 + 为什么"判出来
- 要挑样本做深挖（哪个机构、哪类论据最常错）

## 三种任务

### 任务 A · 冻结与建骨架

```powershell
$env:PYTHONUTF8="1"; $env:PYTHONIOENCODING="utf-8"
cd "04_投研报告分析与回测"
# 按情境自动抽（扎堆 / 下调 / 上调 / 独家 / 头部机构）
python scripts/step4_freeze.py --detail "数据/03_回测结果/backtest_沪深300_20261017_样本明细.jsonl" --n 5 --max-publish 2025-09-15
# 或指定报告
python scripts/step4_freeze.py --info AP202509151744330127
```

产出：`数据/04_全文档案/{info_code}.md`（原文 + sha256）与 `论据库/claims/{claim_id}.md`（骨架）。

### 任务 B · 拆解（本技能的核心）

读 `数据/04_全文档案/{info_code}.md`，按五步填 `论据库/claims/{claim_id}.md`：

1. **一句话论点** —— 必须能判真假
2. **论据池** —— 每条压成"因为 X 所以 Y"，标类型
3. **可证伪性** —— 写不出阈值就填「不可证伪」，这是发现不是偷懒
4. **逻辑缺口** —— 论据到结论跳过了哪一步
5. **不改 front matter 里的冻结字段**（`frozen_at` / `body_sha256` / `px_at_publish` / `eps_*` 一律不许动）

把 `status` 改成 `已拆解`。

### 任务 C · 到期打分

```powershell
python scripts/step5_score.py
```

脚本自动填 `<!-- AUTO:SCORE -->` 区块（区间收益 / 超额 / 目标价是否触及），并刷新 `论据库/_看板.md`。
**人手不要动 AUTO 区块**——它每次运行会覆盖重算。

然后人工填「定性判定」表：每条论据 → 成立 / 部分成立 / 不成立，归因到
`需求没来 / 价格崩了 / 竞争提前 / 自己算错了 / 就是个故事` 五类之一。

数据不够判的，写「待核」并注明缺哪个数据源，**不许猜**。

## 四条硬规矩

1. **反前视**：拆解只用发布日及之前的公开信息。看到结果再回头写论据 = 作废。
2. **判据不许改**：到期发现判据写错了也不能改，另开一条"判据失效"记录。
3. **主口径是中位数超额 + 跑赢率**，不是均值（均值被右尾拉爆：2025 年 12 个月偏多组均值 +14.76%、中位 −10.98%）。
4. **数据不足写「待核」**，绝不编。财报类判据目前系统还没接数据源，一律标待核。

## 当前已知缺口

- 正文只有东财公开摘要（约 1,100–1,600 字），细节论据抽不到
- 未接财报/公告，收入利润类判据无法核
- 目标价仅 7.7% 覆盖 → 目标价只能作辅助口径
