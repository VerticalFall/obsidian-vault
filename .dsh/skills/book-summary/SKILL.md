# book-summary · 书籍核心观点提炼

> 目的：**诚实地还原这本书、这个作者写这本书时表达的核心观点与核心思想**，而不是为了往知识库系统框架里塞而扭曲作者原意。
> 输出：`01_内容系统/知识库/书籍/核心观点/<书名>-核心观点总结.md`（命名与 [[01_内容系统/知识库/书籍/核心观点/_书单索引.md]] 对齐）。

## 〇、用法（一句话）

用户报一个书名 → 先**查证素材**（§二）→ 素材够就按 §三 提炼，不够就按可信度**降级措辞并硬标（待补）**（§四）→ 按 §五 输出 → 按 §八 交付前自查。

**全程三不许**：不许用模型记忆充当作者观点；不许用盗版全文；不许把推定写成事实。

---

## 一、定位与红线

- **忠于原著**：提炼的是**作者的**核心思想，不是我的读后感，更不是为匹配选题池/写作框架做的改编。
- **不绑定系统**：提炼时放下 `_观点.md` 的锚点、"写作可复用框架"、router 标尺书那套系统视角——那些是系统侧的事，最后一步才可选用。
- **不编造（本技能第一红线）**：
  - 没有素材支撑的观点**不写**，标 `（待补）`；
  - **不得**用"我记得这本书好像讲过…"补内容——模型的既有印象**不是素材**，它流畅、听起来对，但无法核实，写进笔记就是把推定洗成作者原话；
  - 素材只有二手转述时，写"据 XX 转述"，不得升格为"作者认为"。
- **区分作者观点与引用观点**：作者批判性引用或转述他人的观点，不算本书核心思想；要单独标注。
- **作者的话优先**：能引用原文表达的思想，不转述成我的措辞。
- **诚实标注可信度**：每一条素材、每一句引句都要能回答"这句话我是从哪看到的"（§二·四）。

---

## 二、素材获取层（上游进料，先做这一步）

> 目标：把"一个书名"变成"一批**可追溯**的素材"。这一步的产出是 §三 提炼的唯一合法输入。

### 一、标定书目（先确认是哪本书，否则后面全白做）

用户给的书名常是简称、错记或译名，必须先锁定：

1. **确认**：书名全称、作者、首版年、是否有多个中译本（译者影响引句措辞）；
2. **消歧**：同名书/同作者多本书（如"原则"→《原则》还是《原则：应对变化中的世界秩序》；"大衰退"→辜朝明哪一本）；
3. **多版本要标**：若为再版/修订版，记下**所依据的版本**——立场漂移只在不同版本间才看得出来；
4. **拿不准就问用户**：候选 ≥2 且差别会影响内容时，宁可问一句（"你指的是 A 还是 B？"），不要猜。**线索可以来自用户**（他提到投资/心理/认知，可缩小范围）。

### 二、来源白名单（只采这些）

| 优先级 | 来源类型 | 能提供什么 | 不可作什么 |
|---|---|---|---|
| **A 级（一手/权威）** | 用户自己提供的书摘/读书笔记/划线圈注；正版试读章节（出版社/Google Books/微信读书试读）；作者本人的访谈、演讲、播客、官网/专栏、公开信；出版社官方书介与作者自序 | 作者观点、可引原句、章节结构 | —— |
| **B 级（二手可信）** | 严肃书评（豆瓣长评中的**有引用**者、报刊书评、学者论文对该书的讨论）；讲书稿/听书稿（得到、樊登等，**注意其本身是转述**）；作者其他书的相互印证 | 观点骨架、常见解读、外部批评 | 不得当作原句；不得升格为"作者认为" |
| **C 级（旁证）** | 维基百科/百科条目、读者短评、二手摘要站、AI 生成摘要站 | 章节名、出版信息、争议线索 | 只能当**线索**，须回 B/A 级验证后才可用 |

**禁止来源（红线）**：
- **盗版全书**（网盘/PDF 站的完整电子书）——即使搜得到也不使用；发现后改从白名单找替代素材，或直接标 `（待补）`；
- 无出处的"XX 分钟读完一本书"这类二次加工品：仅可当**找线索的索引**，不得作为素材写入。

### 三、搜索策略（怎么找够素材）

按"**作者的话 → 结构 → 评价**"三条线各搜一遍：

1. **作者的话**：`"<书名>" 作者 <作者名> 访谈` / `自序` / `演讲`；英文原著搜 `"<English title>" author interview OR lecture`；
2. **结构与章节**：`"<书名>" 豆瓣 笔记` / `目录` / `读书笔记 第X章`——豆瓣笔记与知乎长文是中文书最可靠的 B 级素材来源；
3. **评价与争议**：`"<书名>" 书评 批评` / `review criticism`、作者学术对手的公开回应；
4. **补原句**：`"<书名>" 原文 摘录`（**只取正版试读或书评中带出处的引用**，不点进盗版全文站）；
5. 搜不到的常见原因是**译名/书名不同**——换一两个译名或直接搜作者名再试；仍搜不到才认输。

### 四、素材台账与证据闸门（决定成品能做到什么程度）

收集到的素材先登记成台账，再决定写什么：

```markdown
| # | 素材 | 类型 | 来源 | 级别 | 能支撑什么 |
|---|------|------|------|------|-----------|
| 1 | … | 作者访谈/书评/试读章 | URL + 抓取日期 | A/B/C | 核心思想 2 / 引句 |
```

**证据闸门（硬性）**：

- **一条核心思想至少要有两条独立素材支撑**（不同来源，或一手 + 二手互证）；不足 → 该条降级为"线索级"或直接不写；
- 素材**只够框架、不够论证**时 → 写"**框架级初稿**"（参照 `全球视野下的投资机会-核心观点总结.md` 的写法），**全文标注素材状态**，具体论证一律 `（待补）`；
- 素材几乎为零时 → **不产出笔记**，回报用户"N 条查证路径都失败 + 需要你提供什么"（见 §六），**不留一份看起来完整的空壳**。

## 三、提炼步骤

1. **通读素材台账**（§二·四），而不是"回忆这本书"：识别
    - 作者的**写作动机与背景**：这本书为什么在这个时点写？想回应什么问题？
    - **全书主线**：作者最想说服读者接受的核心命题是什么？
2. **提取核心思想（3–5 条），达到"机制级"而非"标签级"**：
    - 每条 = 作者的一个核心判断 / 命题；
    - 用作者自己的话表达优先，再补一句"作者真正想说的是…"；
    - 能定位就标出处（章节 / 页码 / 素材编号）；**凡出自 B 级素材的表述，写"据 XX 转述"**；
    - **不满足于给结论贴标签，要讲清楚"为什么会得出这个结论"**：支撑它的因果链条或机制是什么，而不是"作者认为 X"就此打住。例如"股价不可预测"不是终点，终点是"为什么不可预测——是信息一旦公开就被套利抹平，还是别的机制"；
    - **主动定位全书核心命题内部的张力或看似矛盾之处**（很多经典著作的深度恰恰在这——立论越有力，往往越逼近自身的悖论）。问自己："如果这个观点被所有人接受并照做，这个观点还成立吗？作者是否处理了这一层，处理得彻底还是留了口子？"
    - **把每条思想放进它所在的思想谱系里**：作者明确回应或反驳的是谁（点名，不要泛泛说"学界"）；后续因为哪些具体证据或哪位学者的挑战，作者的立场发生过怎样的移动——**尤其是多次再版的书，版本间的立场漂移本身就是核心思想的一部分，不能压缩成结尾一句"版本说明"**；
    - **每条思想后紧跟一句"这个论证的真正力度在哪、软肋在哪"**——把"诚实标注"里的边界拆解揉进每一条思想的论述里，而不是全书最后统一打包成一段模板化的边界声明。
3. **提取支撑论证与关键概念**：
    - 作者用了什么论证（案例、数据、隐喻、反例）支撑上述判断；
    - 关键概念 / 术语按**作者的用法**定义，不是通用词典义。
4. **记录可引原句**：3–5 条值得直接引用的金句（注明出处）。**只收台账里的原句**；一条都没有时写"（待补）——暂无可核实引句；不编造"。
5. **诚实标注**：
    - **素材状态**：用了哪些素材、级别如何、哪些部分没有素材（这是本技能新增的必填项）；
    - 本书的**边界**：作者没讲什么、论证薄弱处；
    - 已知的**争议 / 代表性反对观点**（如有）。
6. **产出笔记**：按 §五"输出结构"写入 `核心观点/<书名>-核心观点总结.md`。
7. **登记入册**：在 `_书单索引.md` 追加一行（书名 / 作者 / 素材来源 / 可信度），并更新 §六 素材缺口台账中本书的状态。
8. **表达平衡（专业度 × 接地气，随写随做）**：
    - **自然叙述，不贴标签**：判断、机制、类比、软肋等要素全部融入**连贯叙述**，用「所以 / 于是 / 好比 / 但 / 注意」等连接词自然过渡——禁止出现「判断：」「机制：」「类比：」「软肋：」这类字段式小标题（那是填表，不是阐述）；
    - **每条思想配一个例子**：机制讲完后自然接一个生活化类比（比喻仅帮助理解、不替代证据，拿不准的类比宁可不用）或真实案例（必须是真实发生过的事实，且**来自素材**，不自行编造案例）；
    - **术语首次出现配白话**：如 β「白话：这只股票比大盘"抖"多少倍——大盘跌 1%、β=2 的股票平均跌 2%」；白话只出现一次，之后直接用术语；
    - **反论文腔**：删「值得注意的是 / 综上所述 / 不难发现」；用短句；说完机制直接给例子，别绕；
    - **两头够得着**：专业投资者读后觉得有信息量（机制 + 谱系 + 点名），门外汉读后不劝退（例子 + 白话）——写完用这个标准把每条思想回读一遍。

## 四、可信度 → 措辞对照表（防编造的最后一关）

素材级别不是记录完就算，它**直接约束你能怎么写**：

| 素材级别 | 允许的写法 | 禁止的写法 |
|---|---|---|
| **A 级**（有原句/一手） | 可作事实陈述：「作者在自序里说…」+ 可引原句 | —— |
| **B 级**（二手转述） | 「据 XX 书评转述，作者主张…」；「常见解读认为…」 | 「作者认为…」（无原句支撑的断言式转述） |
| **C 级**（线索） | 仅可用于"值得去 B/A 级核实的线索" | 写入正文当结论 |
| **零素材** | `（待补）`，并说明缺什么、怎么补 | 任何形式的内容填充（含"大致""可能""通常"这类软化词包着的推测） |

**自检口诀**：随手挑笔记里任一句"作者认为…"，问"这句话我在哪个素材里看到的？" —— 答不上来，就该降级或删掉。

## 六、素材缺口台账（查不到时不留空壳，留待办）

书目标定成功但素材不足、或只做到框架级的书，登记到 `核心观点/_书单索引.md` 的「⏳ 素材缺口台账」，便于日后补：

- 记录：书名 / 已试过的查证路径 / 缺什么级别的素材 / 补齐途径（用户提供书摘 / 正版试读 / 等待新版访谈）；
- **同时回报用户**（不要静默留坑）：一句话说明"N 条路径都失败"+"你提供什么我就能做到什么程度"；
- 日后用户提供了素材 → 按 §二 台账重跑该书的 §三 步骤并更新笔记与索引。

---

## 七、与系统侧的衔接（可选，最后一步）

- **默认不做**：不写"写作可复用框架 / 关联选题"，除非用户明确要求。
- 用户要求时，才把提炼结果映射到 `_观点.md` 锚点 / `_选题池.md` / 公众号写作——那是 PM / 写作流程的活，不是本书提炼的职责。

## 八、输出校验（交付前自查）

**素材与溯源**
- [ ] 书目已标定（书名全称 / 作者 / 首版年 / 所依据的中译本）
- [ ] 「素材状态」已填，逐条可追溯（类型 + 来源 + 级别）
- [ ] **零盗版来源**：没有使用盗版全书，也没有把"XX 分钟读完"这类二次加工品当素材
- [ ] **无模型记忆填充**：随手抽 3 句"作者认为…"，每句都能指回某个素材，指不出的已降级/删除
- [ ] 出自 B 级素材的表述均写"据 XX 转述"，未升格为"作者认为"
- [ ] 素材不足处正确降级为「框架级初稿」并全文标注，而非留一份看似完整的成品

**内容质量**
- [ ] 核心思想 3–5 条，条条能追溯到**作者原意**（有素材依据）
- [ ] 无"为系统强扭"的痕迹（没有硬套锚点/选题）
- [ ] 作者观点与转述观点已区分
- [ ] **至少一条思想讲清楚了机制/因果链，而非停在结论罗列**（"作者认为 X"之后，说清了"为什么会是 X"）
- [ ] **至少一条思想点出了全书核心命题内部的张力或悖论**，并说明作者是否处理、处理得彻底还是留了口子
- [ ] 反驳者/后续学者**点名**，而非"学界批评""也有人认为"这类泛称
- [ ] 若为多版本再版书，**版本间的立场漂移**已作为核心思想的一部分写入正文，而非压缩成结尾一句版本说明

**表达**
- [ ] 每条思想至少一个类比或真实案例（且案例来自素材）；术语首次出现有白话解释
- [ ] 每条思想是**连贯叙述**，无「判断：/机制：/类比：/软肋：」字段式小标题
- [ ] 语言平衡：专业读者不觉浅（机制 / 谱系完整）、门外汉不觉劝退（无术语堆砌、无论文腔）

## 九、质量纪律

- **批量入库要警惕质量稀释**：一次提炼多本书时逐本走完 §二 台账与 §四 闸门，**禁止为了凑数把没素材的书"写满"**——一本扎实的笔记 > 五本注水的笔记；
- **宁可薄，不可假**：读者（未来的你）会照着这份笔记引用作者，写错的代价远大于写少的代价；
- **发现已有笔记是"无素材"的高风险条目**（如旧库中自己标注"框架级初稿"者），主动提醒用户可重跑查证补齐。
