# 面试准备优先计划

> 建立：2026-09-03 ｜ 对齐三线时间窗（[[03_求职生涯/求职总纲-时间线与签证节点]]）｜ 对接 03 现有 5 份题库
> 原则：**按面试日历排优先级，不是按题库厚度排**。9 月 = C 线笔试 + A 线 SQL 优先；10 月后 B 线 OT 加码。

## 0. 你要面对的三种面试形态

| | A 线·伦敦立即岗 | B 线·2027 grad scheme | C 线·国内校招 |
|---|---|---|---|
| 流程 | 猎头/HR 电话筛 → 技术面（SQL/Python 实操 30-60min）→ 项目深挖 → 行为面 | 网申 → **OT（数字/逻辑/性格，投后 48-72h 触发）** → 视频面 VI → AC（小组 case + 1v1） | 网申 → **在线笔试（行测 + 专业 SQL/统计/ML）** → 2-3 轮技术面 → HR 面（部分群面） |
| 节奏 | 1-3 周出结果，快 | 跨 2-4 个月 | 笔试后 1-2 周面试，10-11 月密集 |
| 语言 | 全英文 | 英文 | 中文为主 + 备一段英文自我介绍 |
| 你的天然优势 | 项目真实可深挖 | 统计背景 + 金融论文（银行线） | 硕士学校 + 实习对口 |

## 1. 强弱项定位（和简历叙事同一套话术）

**强（面试时主动引导到这些）**
- 统计理论底子 → 概率/假设检验题的主场
- 两个真实上线的开源项目 → 项目面随便深挖（stories 见简历双轨方案 §四）
- 金融+统计复合 → 银行/资管线加分
- LLM 落地经验 → 2026 年全市场热点，A 线初创直接对口
- 中英双语 + 人机结对工作流（独有卖点，但要防"原创性"质疑，见简历方案 §四⚠️）

**弱（按补强优先级排）**
1. **AB 测试/因果推断实操** —— 国内数分岗高频考点，你只有理论没有实践口径
2. **指标体系建设/异动归因** —— C 线业务面必问（"北极星指标怎么定、指标跌了怎么查"）
3. **手撕 SQL 速度** —— C 线笔试 + A 线技术面都考，窗口函数要闭眼写
4. **英文行为面流畅度** —— A/B 线全英文，故事卡要练到脱稿
5. **概率统计速推**（DS 岗）—— 部分 A 线 DS 岗会考，统计底子在，练题型即可

## 3. 分线近期重点（2026-09 → 11）

**C 线（9 月最急，先考先练）**
- 腾讯/平安类：**行测（数量+逻辑）+ 专业题（SQL + 概率统计 + ML 基础）**——专业题 ≈ 101 题 PDF 覆盖范围，行测另找 1-2 套真题练手感
- 四大/宝洁：在线测评（SHL 类：数字推理/逻辑/性格）+ **群面预案**（宝洁八大问英文版、四大的英文 case 讨论）
- 项目口径中文版先备好（国内面试官会追问 stock-monitor 的"数据从哪来、结论怎么验证"）

**A 线（10-11 月高峰，现在起每周积累）**
- SQL 手写：窗口函数 / 自连接 / 留存口径（50 题详解优先做完）
- Python 轻量实操：pandas 清洗/聚合题（不用手撕算法，够用即可）
- 项目深挖口径："为什么这么做 / 数据质量怎么保证 / 结果怎么验证 / 如果重来改什么"——你的素材最足，写出口径稿
- 英文 competency：用 STAR 故事卡，每个故事准备 90 秒版 + 3 分钟版

**B 线（OT 是第一个坑：网申后 48-72h 内触发）**
- 投 Barclays/Revolut/RYI 转正投前，先练 1 轮数字推理+逻辑+情景判断（免费平台够用，不用买课）
- 银行类 VI：录视频答题，练"90 秒内讲完一个成就"的英文结构
- AC 若到（12 月-明年春）：case 框架（利润/成本/定价类）+ 小组讨论的英文抢话技巧，届时再专项
