## 1. 思路（一句话）

你已有两个**真实、每日在跑**的系统（stock-monitor 行情库 + 新闻知识库）——数据是自己的、口径可控、零编造风险。在这两库之上做一次"数仓整合"：把散落的表统一成**星型模型**，产出**指标口径文档**与**自动宽表**，讲一条 取数→清洗→建模→报表 的完整链。

## 2. 设计草案（执行时细化）

- **维度**：dim_date、dim_symbol（标的）、dim_source（信源/平台）、dim_article_topic（新闻主题标签）
- **事实**：fact_daily_report（stock-monitor 日报：日期×标的×指标/估值字段）、fact_article（新闻：日期×来源×主题）、可选 fact_monitor_alert（告警记录）
- **口径文档**：每个指标一行定义 + SQL（如"日报覆盖率 = 实际生成日报数 / 应生成数"、"信源有效占比 = 清洗后入库 / 抓取总数"）
- **自动化**：现有 GitHub Actions 管道尾部追加 mart 层（清洗后直接写星型宽表），再挂现有 ECharts/Tableau 看板

## 3. CV 落点草案（执行后实测填数）

```
**自建数仓整合：行情 + 新闻双系统统一口径**（个人项目，2026）
```
